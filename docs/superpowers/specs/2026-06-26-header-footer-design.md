# Шапка + подвал витрины «Профессионал» — дизайн

**Дата:** 2026-06-26
**Ветка:** `claude/pdp-polish-a`
**Контекст:** самый дешёвый первый шаг визуального сближения `/catalog` (и всей
витрины) с макетами «ИИ Макеты» (`list_products_main.png`, `main.png`): богатая
шапка + подвал. Чистый фронт, без бэкенда и данных.

## Проблема

- `Header` сейчас минимален: логотип + поиск + корзина. В макете — две строки:
  верхняя инфо-панель (регион, телефон 8-800 + график, верхнее меню, иконки
  избранного/сравнения/входа) и основная (логотип, кнопка «Весь каталог», поиск,
  корзина).
- `Footer` отсутствует полностью (grep по `Footer` пуст). В макете — строка
  trust-бейджей, 4 колонки ссылок, способы оплаты, соцсети, копирайт.

Это два самых заметных макет-гэпа, закрываются чистым фронтом за один заход.

## Решения (согласовано)

- **Источник контента — фронт-константы** (`frontend/lib/site.ts`), значения из
  макета, с `TODO` на будущую замену из `SiteSettings.contacts`/`requisites`.
  Бэкенд не трогаем.
- **«Весь каталог»** — пока просто ссылка на `/catalog`, без выпадающего
  мега-меню (мега-меню — отдельной задачей позже).
- **Иконки «Избранное»/«Сравнение»** — визуальные, без перехода (нет рабочих
  роутов; persistence — P2, вне шага). `aria-label` + `title`, без `href`, чтобы
  не плодить 404.
- **Деплой** — диагностика-отчёт (выполнено): `origin/dev` уже тёмный, деплои
  зелёные (последний 2026-06-26 09:00 MSK, hero #287). Светлый скрин устарел —
  снят до выката тёмной темы. Пушей/серверных действий не требуется.

## Архитектура (границы юнитов)

### 1. `frontend/lib/site.ts` — единый источник (новый)

Типизированный экспорт `SITE`. Презентационный конфиг, **никакой логики**.

```ts
export const SITE = {
  brand: { name: "Профессионал", tagline: "территория инструмента" },
  region: "Пенза",
  phone: { display: "8 (800) 600-44-99", href: "tel:+78006004499" },
  schedule: "Пн–Вс 9:00–20:00",
  email: "info@proff58.ru",
  address: "г. Пенза, ул. …",          // placeholder
  topNav: [ { label: "Акции", href: "/promo" }, … ],   // Доставка и оплата, Гарантия, Сервис, Компания, Контакты
  trustBadges: [ { icon, label } … ],   // Офиц. гарантия / Быстрая доставка / Возврат 14 дней / Сервис / Лояльность
  footerColumns: [
    { title: "Каталог",    links: [ … ] },
    { title: "Покупателю", links: [ … ] },   // Доставка и оплата, Гарантия, Возврат, FAQ
    { title: "Компания",   links: [ … ] },   // О нас, Контакты, Вакансии
    { title: "Контакты",   links: [ … ] },   // телефон, email, адрес, график (как текст)
  ],
  socials: [ { label, href, icon } … ],
  payments: ["Картой онлайн", "Наличными", "Безналичный (B2B)", "При получении"],
} as const;
```

Все ссылки — на существующие/будущие роуты витрины; несуществующие помечаются
`TODO`. Замена на API в будущем — правка только этого файла. Значения —
синтетические плейсхолдеры из макета (не продакшен-данные).

### 2. `frontend/components/layout/Header.tsx` — обогащение (правка)

Остаётся `"use client"` (нужен `useCart`). Две строки:

- **TopBar** (выносится в подкомпонент `frontend/components/layout/TopBar.tsx`
  для читаемости): слева — регион (`MapPin`); по центру/справа — телефон
  (`Phone`) + график (`Clock`); верхнее меню (`SITE.topNav`); иконки
  «Избранное» (`Heart`), «Сравнение» (`GitCompare`), «Вход» (`User`).
  На мобильном TopBar сворачивается: остаются телефон + (меню `hidden md:flex`).
- **MainBar**: логотип (ссылка `/`) · кнопка **«Весь каталог»** (`Link href="/catalog"`,
  акцентная) · `SearchBar` (flex-1) · корзина (как сейчас, со счётчиком).

Иконки избранного/сравнения — `<button type="button">` с `aria-label`/`title`,
без действия (визуальные). Корзина и вход — реальные ссылки (`/cart`, вход — на
существующий роут или `TODO`).

### 3. `frontend/components/layout/Footer.tsx` — новый (server-компонент)

Без состояния → серверный. Рендерит из `SITE`:

- строка **trust-бейджей** (иконка + подпись, `SITE.trustBadges`);
- **4 колонки** ссылок (`SITE.footerColumns`), колонка «Контакты» — телефон/email/
  адрес/график как текст;
- **способы оплаты** (`SITE.payments`) — простые текстовые бейджи (без брендовых SVG);
- **соцсети** (`SITE.socials`) — иконки `lucide-react`;
- **копирайт** + регион.

Семантика: `<footer>`, списки `<ul>`, ссылки `<a>`/`Link`. Адаптив: колонки
`grid-cols-2 md:grid-cols-4`.

### 4. `frontend/app/layout.tsx` — правка

- Импорт `Footer`.
- Обернуть содержимое в флекс-колонку: внутренний контейнер
  `flex min-h-screen flex-col`; `main`/`children` — `flex-1`; `<Footer />` после.
  Footer прижимается к низу даже на коротких страницах.

## Зависимости и стиль

- Только существующие бренд-токены (`bg-surface`, `bg-raised`, `border-line`,
  `text-ink`/`-2`/`-3`, `text-accent`, `font-display`).
- Иконки — `lucide-react` (`Phone`, `Clock`, `MapPin`, `Heart`, `GitCompare`,
  `User`, `ShoppingCart`, соц-иконки).
- Способы оплаты — текстовые бейджи, без брендовых картинок (дёшево, без ассетов).

## Тестирование / проверка

Статичная презентация без логики — юнит-тесты не заводим. Проверка:

- `npm run build` (или `tsc --noEmit`) — типы и сборка зелёные.
- Визуальная сверка с макетом (`list_products_main.png`) — по желанию через браузер
  на dev-сервере фронта.

## Вне рамок

- Мега-меню «Весь каталог» (выпадающее дерево категорий).
- Рабочее избранное/сравнение (роуты + persistence) — P2.
- Привязка контента к `SiteSettings` API/BFF.
- Реальные фото товаров (контент-трек).
- Главная страница, hero-баннер.
