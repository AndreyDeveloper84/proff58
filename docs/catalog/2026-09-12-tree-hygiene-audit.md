1. **Лезвия — 72, не 54**, и не однородно: 58 сменных лезвий + 8 ножей с ложным типом

2. **Отвесы «без типа» — неверно:** тип верный, дефект — отсутствие листа: все 60

3. **Лебёдки — 33 вне листа, окаменелость только 15** (ложный тип «таль ⊂ стальной»,
   категория у половины верна); остальные 18 — свои электротали с верным типом.

   «круг/круглый» (круглогубцы, ключи для круглых гаек, кисти, молотки с круглым
   бойком); 63 из 64 неактивны.
5. **Числа занижены:** в корне 57 — 20 (не 16), для припоев уже есть тип
   `raskhodniki-pajki`; чужих в мешках пылесосов 19 (не 6), 13 в наличии; «баков» в
