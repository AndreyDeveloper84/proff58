## 1. nasosy-drenazhnye-fekalnye — «Насосы дренажные и фекальные»

- **Входит:** погружные насосы для грязной/сточной воды, дренажные, фекальные,
  канализационные, вихревые погружные для загрязнённой воды.
- **Не входит:** скважинные (чистая вода), циркуляционные (отопление), поверхностные.
- **Примеры:** ГНОМ 7х7; Насос для грязной воды ГНОМ 25-20Т; Насос дренажный ЗУБР 300/400 Вт;
  Насос канализационный КН-500 Вихрь; Насос Т7 АкваСенсор погружной ЗУБР; погружной STURM WP9790.
- **Expected count/pub:** ~59 / ~20.
- **FP-риск:** средний — «погружной» без уточнения может оказаться скважинным; фекальные и
  дренажные объединяем в один tool_type сознательно.
- **Ключевые слова (для `product_type_rules`):** `дренажн`, `фекальн`, `для грязной воды`,
  `гном`, `канализацион`, `аквасенсор`, `погружной`(+`грязн`).
- **Excludes:** `скважинн`, `эцв`, `циркуляцион`, `поверхностн`, `вибрацион`.

## 2. nasosy-poverhnostnye — «Насосы поверхностные»

- **Входит:** поверхностные самовсасывающие, садово-бытовые, повысительные (повышение
  давления), струйные (инжекторные), центробежные консольные/моноблочные (в т.ч. промышленные).
- **Не входит:** любые погружные (дренажные/скважинные/вибрационные), циркуляционные.
- **Примеры:** Джамбо 60/35Н; ПН-1100Н Вихрь; Metabo P 3300 G; повысительный STURM WP2008W;
  Calpeda MXHM 802; Насос консольно-моноблочный КМ 65-50-160.
- **Expected count/pub:** ~30 / ~5.
- **FP-риск:** средний — промышленные центробежные (Calpeda/EBARA/WILO/КМ/К) при желании
  можно выделить в отдельный подтип «промышленные»; повысительные — на грани с автоматикой.
- **Ключевые слова:** `поверхностн`, `самовсасыв`, `джамбо`, `повысительн`,
  `повышение давления`, `консольн`, `моноблочн`, `км `, `струйн`, `инжектор`.
- **Excludes:** `погружн`, `скважинн`, `дренажн`, `циркуляцион`, `вибрацион`.

## 3. nasosy-cirkulyacionnye — «Насосы циркуляционные»

- **Входит:** циркуляционные насосы для отопления/ГВС.
- **Не входит:** водоподъёмные (поверхностные/скважинные/дренажные/вибрационные).
- **Примеры:** ЦН-32/8 ВИХРЬ; WILO TOP-S 40/15; EVOPLUS B 120/220 SAN; VHSL Protherm; Calpeda NM/NRM.
- **Expected count/pub:** ~33 / ~1 (почти всё скрыто — на витрине появится мало).
- **FP-риск:** низкий (термин однозначен).
- **Ключевые слова:** `циркуляцион`, `цн-`, `для отопления`.
- **Excludes:** —.

## 4. nasosy-skvazhinnye — «Насосы скважинные»

- **Входит:** скважинные и колодезные глубинные насосы (Водомет, СН, ЭЦВ), центробежные скважинные.
- **Не входит:** поверхностные, дренажные, **вибрационные** (у них свой подтип, хотя ставятся в скважину).
- **Примеры:** Насос скважинный Водомет ПРОФ 40/50; СН-100/135; колодезный Водомет 150/60А;
  скваженный STURM WP9705.
- **Expected count/pub:** ~28 / ~8.
- **FP-риск:** средний — «Водомет» бывает скважинный и колодезный (объединяем); отсекать вибрационные.
- **Ключевые слова:** `скважинн`, `скваженн`, `эцв`, `колодезн`, `водомет`, `глубинный насос`.
- **Excludes:** `вибрацион`, `дренажн`, `поверхностн`, `циркуляцион`.

## 5. nasosy-vibracionnye — «Насосы вибрационные»

- **Входит:** вибрационные насосы (Малыш/Ручеёк/Родничок/ВН), с верхним/нижним забором воды.
- **Не входит:** центробежные скважинные, дренажные.
- **Примеры:** ВН-10Н Вихрь; ВН-25В Вихрь; Родничок-Н ЗУБР (нижний забор).
- **Expected count/pub:** 23 / 6.
- **FP-риск:** низкий (термин однозначен).
- **Ключевые слова:** `вибрацион`, `малыш`, `ручеек`, `ручеёк`, `родничок`, `вн-`.
- **Excludes:** —.

## 6. nasosnye-stancii — «Насосные станции»

- **Входит:** автоматические станции водоснабжения (насос + гидробак + автоматика в сборе), АСВ.
- **Не входит:** одиночные насосы; автоматика без насоса (→ подтип 7).
- **Примеры:** Станция водоснабжения автоматическая АСВ-1200/24; АСВ-800/24; АСВ-1200/50.
- **Expected count/pub:** 9 / 4.
- **FP-риск:** низкий.
- **Ключевые слова:** `станция водоснабж`, `насосная станц`, `асв-`, `асв `.
- **Excludes:** `станция управлен` (это автоматика, подтип 7).

## 7. avtomatika-dlya-nasosov — «Автоматика для насосов»

- **Входит:** реле давления, станции управления/защиты (СУЗ, ЛОЦМАН), преобразователи частоты
  (для насосов), пульты управления (Pedrollo QET).
- **Не входит:** сами насосы, насосные станции (с насосом в сборе).
- **Примеры:** Преобразователь напряжения и частоты СМТ35/55; Станция управления СУЗ-100/40;
  Пульт управления Pedrollo QET; Станция управления и защиты ЛОЦМАН.
- **Expected count/pub:** 6 / 0.
- **FP-риск:** средний — «преобразователь частоты» бывает общепромышленным (не только для
  насосов); проверять контекст/бренд.
- **Ключевые слова:** `реле давлен`, `станция управлен`, `суз-`, `пульт управлен`,
  `преобразователь напряжения и частоты`, `лоцман`.
- **Excludes:** `станция водоснабж` (это подтип 6).

## 8. komplektuyuschie-dlya-nasosov — «Комплектующие для насосов»

- **Входит:** корпуса, рабочие колёса/крыльчатки, оголовки скважин, обратные клапаны,
  гидроаккумуляторы/гидробаки, мембраны, ремкомплекты к насосам.
- **Не входит:** сами насосы, автоматика, общая оснастка не про насосы.
- **Примеры:** Корпус насоса STURM WP.
- **Expected count/pub:** ~1 / 0 (в текущем хвосте почти пусто; наполнится из других источников).
- **FP-риск:** низкий, но пересечение с общей оснасткой — брать только явно «для насоса».
- **Ключевые слова:** `корпус насоса`, `рабочее колесо`, `крыльчатк`, `оголовок`,
  `обратный клапан`, `гидроаккум`, `гидробак`, `мембран`, `ремкомплект к насос`.
- **Excludes:** —.

## 9. motopompy — «Мотопомпы»

- **Входит:** бензиновые/дизельные мотопомпы для воды (чистой/грязной/пожарные).
- **Не входит:** электрические насосы (все подтипы выше).
- **Примеры:** в текущем хвосте id=3 отсутствуют (типизированы/в других узлах); из ассортимента —
  мотопомпы Huter/Champion/Elitech.
- **Expected count/pub:** 0 / 0 в текущем хвосте — **подтип заводим на будущее** (наполнение из других источников).
- **FP-риск:** низкий.
- **Ключевые слова:** `мотопомп`.
- **Excludes:** —.

## Guardrails классификации

- **Keywords — это кандидаты, не готовые regex-правила.** Финальные `product_type_rules`
  фиксируются только после проверки на **dry-run**.
- **Маршрутизация — только по присвоенному `tool_type`, не напрямую по имени товара.**
- **Широкие/аббревиатурные ключи** (`КМ`, `ЦН`, `ВН`, `АСВ`, `обратный клапан`, `мембрана`,
  `пульт`, `преобразователь`) применять ТОЛЬКО в **насосном контексте** (в связке с
  «насос»/«водоснабж»/насосным брендом), иначе высокий FP.

## Global excludes (для всех подтипов)

Не относить к разделу «Насосы» ни при каком подтипе (пересекается с FP 10):
`ножной`, `автонасос`, `НШ`, `молочный`, `опрессовка`, `плунжерный`,
`АВД`/`мойка высокого давления`, `битум`/`ДС-134`, `лабораторный`/`трансферный`.

## EAV-долг (фасеты)

У насосного хвоста **нет характеристик в EAV** (`ATTR_UNIQUE=0` на 202). Раздел заводится
«пустым по фильтрам»; фасеты проектируются и наполняются отдельным enrich-объёмом:

- тип насоса (подтип), назначение (чистая/грязная вода, отопление, скважина, полив);
- производительность (л/мин · м³/ч), напор (м), глубина погружения/всасывания (м);
- мощность (Вт), Ø скважины (дюйм/мм), забор воды (верхний/нижний — для вибрационных);
- бренд (⚠️ поле `brand` пустое — проставить в round-е).
