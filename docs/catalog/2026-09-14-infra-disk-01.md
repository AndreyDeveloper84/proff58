TRACK RESUMED**. Не failure трека VI-INT-18: STOP сработал корректно до
первой записи.

## 2. Read-only аудит (без единого удаления)

- **Основной потребитель: Docker build cache ≈ 13,9 ГБ** (203 записи,
  **0 active, весь reclaimable**).

- Staging backups: 4,0 ГБ (media-*.tgz с вероятными дублями ~0,75 ГБ;
  старые db-дампы ~2 ГБ) — классифицированы, не тронуты.

  dev_postgres), ATTACHED_ACTIVE, DETACHED_BUT_UNKNOWN (6 шт — без
  доказательства safe не удаляются). **Volumes не удалялись.**
- Часть дерева не измерена (тяжёлые `du` рвались на IO-стрессе):
  ~24–28 ГБ помечено UNKNOWN, не «предположение о PostgreSQL/media».

## 3. Выполненный cleanup (OWNER GO, шаги 1–2)

Реально выполнено ровно два действия:

1. `docker builder prune -f` — reclaim ≈ 13,9 ГБ;
2. `docker image prune -f` — reclaim ≈ 3,2 ГБ (dangling).

Результат: **~734 МБ free → ~11 ГБ free**. Обе команды стандартные и
обратимые пересборкой. Никаких других команд «рассматривалось, но не
выполнялось».

## 7. Выводы
