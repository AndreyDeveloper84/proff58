## C. Existing importer archaeology

Файлы (deployed, proff58_staging-web-1):
`apps/catalog/scraped_import.py` (1068 строк) +
`apps/catalog/management/commands/catalog_import_scraped.py` (381).

Flow: export JSON (`{"source", "products":[card]}`) → `--category <slug>` →
карта `scraped_attr_map.<slug>.json` → `extract_card_values` (карта полей →
оси, fail-closed гейт единиц ДРФ-1440) → `match_card` (лестница
**SKU → exact_model → normalized_model → alias**, бренд-токен из
BRAND_VOCABULARY обязателен) → разрешение «многие к одному» по LADDER_RANK →
`plan_product_values` (**create / confirm / conflict / skipped_voltage**;
автоматический overwrite ЗАПРЕЩЁН — CODE-04, любое расхождение в conflict) →
`--dry-run` = полный план без единой записи (включая ImportRun).

Input contract карточки: `name`, `brand`, `manufacturer_sku`, `source_url`,
`attributes: {подпись поля: сырое значение}` (+ опциональные `summary_raw`).
Скоуп товаров: `tool_type` ∈ scope_tool_types карты.
**Explicit resolved product_id importer НЕ принимает** (gap, см. F).
Изображения importer НЕ обрабатывает — отдельный `image_pipeline.py`.

## I. Units/value formats

VI: `unit=null`, единицы inline в value, форматы: «125 мм», «30 м», «800»,
«0.9», boolean-строки, enum-строки, multi-value. Гейт ДРФ-1440 схему карты
пропустил, но **покарточечный разнобой единиц гейт не видит** — GAP-2:
- 36918 «Длина» = «30 м» → length(мм) планирует **30.0** (верно 30000);
- 41821 «Длина» = «200» (проволока, метры) → length(мм) **200.0**
  (верно 200000);
- 44891 «Мощность двигателя» = «90» (станок 90 Вт) → **power_hp 90.0 л.с.**
  (DIRECT-имя попало на ось бензоинструмента).
Остальные 28 creates ручной сверкой чисты (включая корректные «120 мм»,
«2600»→power Вт, 18 В battery→voltage create, 220 В mains→skipped_voltage).
Действие для map v2: «Длина» и «Мощность двигателя» → unmapped (или
unit-aware extract отдельным этапом).

## J. Images (все 69 refs)

Команда catalog_import_scraped изображения не обрабатывает — это норма
архитектуры, а не дефект: для медиа существует `ImagePipeline.process_batch`

(существующие не трогает), `is_main` только если у товара нет фото,
идемпотентность по `(product, source_url)` и `(product, checksum)`,
`content_locked` уважается, `manual` в batch запрещён (откатываемость),
throttle по хосту, SSRF-защита. **GAP-4**: enum `ImageSource` = {manual,
resanta, vihr, interskol, zubr} — значения `vseinstrumenti` нет (14 симв.,
max_length=16 влезает); +1 строка enum (миграция choices) для sandbox.
