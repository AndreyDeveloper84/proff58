## 1. Точное изменение ImagePipeline

`apps/catalog/image_pipeline.py` (минимальный diff, обратная
совместимость вызовов сохранена):

- `process_url` — решение о main принимается в момент **создания** записи:
  было `first = not product.images.exists()` / `is_main=is_main or first`,
  стало `has_main = product.images.filter(is_main=True).exists()` /
  `is_main=is_main or not has_main`. Существующий main не читается на
  предмет изменения и не UPDATE'ится вообще. Дедуп-ветки (return
  existing по `(product, source_url)` до сети, return same_bytes по
  `(product, checksum)` после) не тронуты — дедуп не создание, на main
  не влияет. Явный параметр `is_main` сохранён (ручной вызов с
  `is_main=True` — сознательное действие вызывающего).
- `process_batch` — убрано форсирование `is_main=(i == 0)` (именно оно
  создавало второй main у 2092/6794/7057 в VI-INT-02). При отсутствующем
  main его получает **первое реально созданное** изображение пачки.
- Docstring'и обоих методов описывают новый инвариант.

Legacy-галереи (0 или 2+ main) не нормализуются — отдельный data-cleanup
track, здесь только read-only аудит (п. 7).

## 3. sort_order — исследование (без изменений)

Фактический контракт: `sort_order` default 0, pipeline его не ставит,
`Meta.ordering = ["-is_main", "sort_order"]` — без tie-breaker; витрина —
голый `prefetch_related("images")` (views.py), main сериализатор берёт как
`next(i for i in images if i.is_main)` (serializers.py:141).

- **Главное фото детерминировано**: main ровно один → находится
  независимо от порядка строк.
- **GAP (косметический, НЕ исправлено в этом треке):** порядок
  secondary-изображений в `get_images` (serializers.py:189) при
  равных `sort_order=0` не подпёрт уникальным tie-breaker — Postgres
  порядок равных ключей не гарантирует. Затронут только взаимный порядок
  миниатюр галереи у импортированных товаров; на главное фото не влияет.
  Минимальные варианты (на решение владельца): (а) добавить `"pk"` в
  `Meta.ordering`; (б) проставлять `sort_order` в pipeline; (в) точечный
  `Prefetch` с `order_by("-is_main","sort_order","pk")` на витрине.
