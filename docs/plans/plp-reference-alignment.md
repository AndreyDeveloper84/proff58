# PLP — выравнивание реализации с визуальным референсом

## Цель

Привести страницу категории PLP к референсу:

- исходный файл: `/home/shiro/Загрузки/ChatGPT Image 16 июл. 2026 г., 14_19_54.png`;
- референс содержит desktop-композицию, мобильную PLP и мобильный drawer фильтров;
- контрольные размеры реализации: `1440×900`, `390×844`, дополнительно `320`, `360`, `768`.

## Общие ограничения

- Не менять контракты каталожного API, фильтрации и URL без отдельной необходимости.
- Сохранить SSR-выдачу, `aria-live`, focus trap/Escape drawer и touch-target не меньше 44 px.
- Избранное не должно становиться рабочей Wave 1-функцией только ради визуального совпадения:
  допустима неактивная/скрываемая кнопка либо feature flag.
- Использовать семантические токены, не добавлять raw hex в компоненты.
- После каждого этапа проверять desktop и mobile, а не полировать только один viewport.

## PLP-00 · Зафиксировать референс и baseline

**Приоритет:** P0  
**Блокирует:** все задачи визуального выравнивания.

### Работы

1. Скопировать референс в `docs/design/references/plp-target.png`.
2. Снять текущие скриншоты `/catalog/perforatory`:
   - `1440×900`;
   - `390×844`;
   - открытый drawer фильтров `390×844`.
3. Сохранить их в `docs/design/references/current/`.
4. Зафиксировать URL, режим данных и commit SHA, на котором сняты скриншоты.

### Приёмка

- Референс и baseline находятся в репозитории.
- Сравнение можно повторить без доступа к истории чата или папке «Загрузки».

**Приоритет:** P0  
**Файлы:** `frontend/components/layout/Header.tsx`, `SearchBar.tsx`.
