## 2. Схема характеристик уже готова

У категории «Электроинструмент» (`cat=3`) настроено 15 `CategoryAttribute`, из них
для перфораторов релевантны: `power` (мощность), `chuck` (тип патрона),
`energy_impact` (энергия удара), `no_load_speed` (обороты х.х.), `voltage`,
`power_source`, `motor_type`, `battery_capacity`, `battery_included`.

Новые `Attribute` создавать не требуется.

## 4. Ключевые находки, влияющие на план

### 4.1. Артикулы — настоящие каталожные номера производителя

```
'0611254768'      Перф. Bosch GBH 2-26DFR; 800Вт, SDS+, 3Дж, 3реж
'BSH-0611240008'  Перф. Bosch GBH 5-38D; 1050Вт, SDS-MAX, 5,9Дж
'061123A000'      Перф. Bosch GBH 3-28DRE; 800Вт, SDS+, 3,5Дж
```

Это официальные номера Bosch, часть — с префиксом поставщика `BSH-`.
**Матчинг по артикулу производителя реален**, нужна нормализация префиксов.
Это снимает главный риск R1 роадмапа — по крайней мере для части выборки.

### 4.2. Характеристики уже лежат в названиях

`«710Вт, SDS+, 2,5Дж, 2реж, 0-900об/мин»` — в названии из 1С уже присутствуют
мощность, тип патрона, энергия удара, число режимов и обороты. То есть **ядро
характеристик перфоратора извлекается регулярками из наших же данных**, без
обращения к внешнему сайту.

Следствие: первый результат достижим до парсера и без правовых вопросов —
см. Phase 0.5 в роадмапе.

### 4.3. Поле `brand` пустое у всех

Матчинг «бренд + артикул» в исходном виде не работает: бренд надо извлекать из
названия (есть `apps/catalog/brand_slugs.py`).

### 4.4. «Дрели и шуруповёрты» — сборный тип, в пилот не берём

Опция `id=3` (673 товара) смешивает дрели, шуруповёрты и гайковёрты. Карта
характеристик для такой смеси будет размытой. Разделение типов — отдельное
продуктовое решение владельца, после пилота на перфораторах.

## 5. Источник

Категория перфораторов на сайте-источнике — URL фиксируется на Phase 1 вместе с
проверкой доступности данных по HTTP.

## 6. Критерий успеха пилота

Из 188 перфораторов:
- значимая доля получила мощность, тип патрона и энергию удара в EAV;
- фасеты по этим характеристикам стали рабочими фильтрами;
- цена, остаток, категория и `tool_type` не изменились ни у одного товара.
