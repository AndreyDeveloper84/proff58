# Таксономия v2 — передеренные счётчики (классификатор round 1)

- Метод: единый словарь `раздел→подтип→ключевые слова` по **всему** каталогу
  (`data/catalog_fixed.json`, 47 224 поз.); счётчики раздельно **в наличии / всего**.

  (хвост 37% — преимущественно нулевые/архив, на round 2 словаря).
