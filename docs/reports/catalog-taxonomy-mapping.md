## Принцип маппинга 1С → публичная категория

- Ключ связи — `external_id` **родительской** группы 1С (стабилен; имя не уникально). Маппинг ведётся в `data/group_mapping.json`.
- Бренд из имени группы → `Product.brand`, не в категорию (находки F4).
- Характеристика из имени группы → EAV-атрибут, не в категорию.
- Грязь/служебные группы 1С → `on_site:false` (скрытый корень, ADR-0002).
- Внутренние под-типы (Буры/Свёрла/Метчики…) берутся из 1С-подгрупп либо из `tool_type` по названию — публичная иерархия не обязана повторять 1С.
