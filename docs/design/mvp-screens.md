# MVP · Макеты ключевых экранов (#40)

Кодовые макеты пользовательских сценариев витрины «Профессионал», собранные из
SP2-кита (см. [`sp2-design-system.md`](sp2-design-system.md)). Живой эталон —
страница **`/demo/screens`**. Это референс вёрстки: раскладка и состояния зафиксированы,
живых данных нет — не блокирует API-разработку.

## Экраны и покрытие

| # | Экран | Ключевые блоки | Состояния |
|---|-------|----------------|-----------|
| 1 | Главная / категории | Hero (Card raised + CTA), сетка категорий | — |
| 2 | Список товаров (PLP) | Sidebar фасетов (desktop) / «Фильтры» (mobile), сетка `ProductCard` | наличие / под заказ / нет в наличии |
| 2б | Состояния списка | — | loading · пусто · ошибка |
| 3 | Карточка товара (PDP) | Галерея, характеристики (Card), блок покупки | в наличии; «нет» → CTA «Узнать о поступлении» |
| 4 | Корзина и оформление | Список позиций, форма контактов (Field/Input/Textarea), сводка (товары/доставка/НДС/итог) | — |
| 4б | Заказ оформлен | `SuccessState` + счёт на email | success |
| 5 | Личный кабинет | История заказов (Card + Badge статуса) | пусто |

## Адаптив (desktop / mobile)

- **PLP**: `lg:grid-cols-[220px_1fr]` — фасеты сайдбаром на desktop; на mobile сайдбар
  скрыт (`hidden lg:block`), доступ через кнопку «Фильтры» (bottom-sheet — Фаза 3 #222).
- **PDP**: `lg:grid-cols-2` — галерея и покупка рядом на desktop, стек на mobile.
- **Checkout**: `lg:grid-cols-[1fr_320px]` — форма + липкая сводка на desktop, стек на mobile.
- **Сетка карточек/категорий**: `grid-cols-1 sm:grid-cols-2 xl:grid-cols-3`.

## Состояния (единые из SP2)

`наличие` — через `ProductCard`/`Badge` (`in`/`order`/`out`); `loading` —
`LoadingState`; `пусто` — `EmptyState`; `ошибка` — `ErrorState`; `успех` —
`SuccessState`. Компоненты — `frontend/components/ui/states.tsx`.

## Соответствие контрактам

- **Checkout-сводка** отражает контракт ADR #444 / M-06: строки товары · доставка ·
  «в т.ч. НДС 22%» · итог (см. [`sp2-design-system.md`](sp2-design-system.md) и #430/#429).
- **Catalog-first**: PLP с фасетами и `tool_type`-навигацией — по roadmap #222.

Все базовые решения по раскладке и состояниям зафиксированы — вёрстка реальных
страниц (`app/**`) идёт без новых дизайн-развилок.
