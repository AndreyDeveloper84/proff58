# Постраничное ТЗ — Поиск (подсказки + выдача) · Wave 1

Детализация к контракту `../tz-master.md` и `../../design.md` (токены §9). Ранее был кратко
в `plp.md` §12 — вынесен в отдельный экран, т.к. у поиска свои подсказки и empty.

---

## 1. Назначение и место в флоу
**Цель:** найти товар по **артикулу / модели / бренду** и перейти в PDP/PLP. Откуда: поле в
шапке (на всех страницах). Ведём к: PDP (точное совпадение) / страница выдачи (список).
Поиск — критичный путь для профи, которые ищут по конкретной модели.

## 2. Компоненты

### 2.1 Поле поиска (в шапке)
Крупное поле (desktop h48), иконка-лупа, плейсхолдер «Артикул, модель или бренд». На mobile —
иконка, разворачивается в полноэкранное поле.

### 2.2 Поповер подсказок (по вводу)
Группы: **Товары** (мини-строка: фото + название + цена + наличие), **Категории**, **Бренды**,
недавние/популярные запросы. Подсветка совпадения. Кнопка «Показать все результаты по “…”».

### 2.3 Страница выдачи
= PLP **без дерева категории**: заголовок «Найдено N по “запрос”» + фасеты + сетка карточек
(единый шаблон) + сортировка + подгрузка. Сохранение запроса в поле.

## 3. Состояния (обязательные фреймы)

| Состояние | Что показываем |
|---|---|
| **Пустой фокус (нет ввода)** | недавние/популярные запросы, топ-категории |
| **Ввод → подсказки loading** | скелет-строки в поповере |
| **Подсказки есть** | сгруппированные результаты + «Показать все» |
| **Подсказок нет** | «Ничего не найдено. Проверьте артикул» + ссылки на каталог/популярное |
| **Выдача: loading** | скелет-сетка |
| **Выдача: есть результаты** | «Найдено N по “запрос”» + сетка + фасеты |
| **Выдача: 0 результатов** | «Ничего не нашли по “…”. Проверьте артикул или сбросьте фильтры» + популярное/похожее |
| **Error/retry** | «Не удалось выполнить поиск. Повторить» |
| **Наличие в карточках/подсказках** | цвет+иконка+текст |

## 4. Интеракции и микрокопи
- Ввод с debounce; подсказки обновляются по мере набора.
- Клавиатура: ↑/↓ по подсказкам, Enter — переход (в выделенную/на страницу выдачи), Esc —
  закрыть поповер.
- Клик по товару-подсказке → PDP; по «Показать все» / Enter → выдача.
- Сохранение недавних запросов (локально), очистка.
- Тексты — конкретные, без воды; терминология пользователя.

## 5. Адаптив
Desktop — поповер под полем шапки. Mobile/tablet — **полноэкранный поиск** (поле сверху,
подсказки на весь экран, «Отмена»). Выдача — как PLP (2/3/4/5). Проверить 320/360/390/768/1440;
элементы подсказок тач ≥44.

## 6. Доступность (важно — паттерн combobox)
- Поле — `role="combobox"`, `aria-expanded`, `aria-controls`, активный элемент —
  `aria-activedescendant`; список подсказок — `role="listbox"`, пункты `role="option"`.
- Полная клавиатурная навигация (↑/↓/Enter/Esc); число результатов подсказок — `aria-live`.
- Полноэкранный поиск (mobile): focus trap + возврат фокуса на иконку поиска по «Отмена».
- Контраст AA; статус наличия цвет+иконка+текст; фокус виден.

## 7. Моушн (спокойный)
Появление поповера — мягкое; без параллакса. Reduced-motion — мгновенно.

## 8. Измеримость
| Событие | Триггер |
|---|---|
| `search` | отправка запроса (Enter/«показать все») |
| `search_suggest_shown` | показ подсказок |
| `search_suggest_click` | клик по подсказке |
| `search_result_click` | клик в выдаче → PDP |
| `search_zero_results` | 0 результатов |
Guardrail: доля нулевых выдач; доля поисков без клика.

## 9. Acceptance criteria (Поиск)
- [ ] Поиск по артикулу/модели/бренду; подсказки сгруппированы (товары/категории/бренды).
- [ ] Все состояния: пустой фокус / loading / есть / нет подсказок / выдача loading/есть/0 / error.
- [ ] Empty выдачи ведёт дальше (популярное/похожее/сброс), не тупик.
- [ ] Combobox-доступность (роли/aria, ↑↓/Enter/Esc); подсказки `aria-live`.
- [ ] Mobile: полноэкранный поиск (focus trap, «Отмена» возвращает фокус); тач ≥44.
- [ ] Выдача = PLP без дерева; единый шаблон карточки; наличие цвет+иконка+текст.
- [ ] Токены `design.md`; адаптив 320/360; моушн спокойный, reduced-motion.

## 10. Открытые вопросы (для этой страницы)
1. Толерантность к опечаткам/раскладке (важно для артикулов) — есть на бэке?
2. Поиск по синонимам/народным названиям («болгарка» → УШМ) — на запуск?
3. Перспектива AI-подбор/сравнение — точка входа из поиска (Wave 3) — резервируем место?
4. Хранить недавние запросы локально или в кабинете (для авторизованных)?
