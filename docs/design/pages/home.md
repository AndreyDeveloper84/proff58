# Постраничное ТЗ — Главная · Wave 1

Детализация к контракту `../tz-master.md`, концепции главной `../../design.md` §17
(«Clean Workshop Parallax») и токенам §9. Главная — **wow-зона №1** (первый экран +
баннер консультации), остальное спокойное.

---

## 1. Назначение и место в флоу
**Цель:** продать масштаб и профессиональность за первый экран и **быстро увести в каталог/
поиск**. Откуда: реклама, прямой заход, повтор. Ведём к: Категория/PLP, Поиск, PDP (хиты),
Консультация в MAX. Не мешаем покупать: поиск и «Каталог» доступны сразу.

## 2. Раскладка (блоки сверху вниз)
1. **Hero-параллакс (5 слоёв, слайдер категорий)** — `design.md` §17.2: фон-мастерская blur →
   чертёжный SVG со схемой + метки → детали/маркеры → крупный реальный инструмент (3D от мыши)
   → UI-текст (заголовок «ПРОФЕССИОНАЛЬНЫЙ ИНСТРУМЕНТ / для тех, кто работает точно» + 4 УТП
   + CTA «Перейти в каталог» / «Получить консультацию»). Точки-слайдер 01–02–03, стрелки.
2. **Категории-витрина** — 6 карточек (Электроинструмент, Бензоинструмент, Садовая техника,
   Сварочное, Оснастка, Расходные) с количеством товаров, зелёной стрелкой, hover-подъёмом.
3. **Хиты продаж** — карусель карточек (единый шаблон), «Смотреть все».
4. **Баннер консультации** (**wow-зона №2**) — «Не знаете, какой инструмент выбрать?» +
   эксперт, параллакс фона, «Получить консультацию» / «Консультация в MAX» (pulse 1 раз).
5. **Преимущества** — 5 иконок (гарантия / доставка / самовывоз / сервис / оплата).
6. **О магазине** — статичная стилизованная карта Пензы (пин) + цифры (10+/20000+/50000+/100+
   — **placeholder до подтверждения**), «Подробнее о компании».
7. **Подписка** (e-mail) + подвал.

## 3. Состояния (обязательные фреймы)

| Состояние | Что показываем |
|---|---|
| **Loading** | скелетоны секций (hero-плейсхолдер, скелет-карточки категорий/хитов) |
| **Базовое** | полный контент |
| **Reduced-motion** | статичный hero (без параллакса/3D), reveal → fade без сдвига |
| **Error/retry (блок хитов/категорий)** | «Не удалось загрузить. Повторить» на уровне секции, не всей страницы |
| **Наличие в карточках хитов** | в наличии/мало/под заказ/нет (цвет+иконка+текст) |

## 4. Моушн (главная wow-зона — но дозированно)
- **Только desktop ≥1024:** pointer-parallax hero (слои с разной скоростью, инструмент
  translate+rotate 1–2°), scroll-параллакс hero (scale-down, чертёж → opacity 0), баннер
  консультации (фон медленнее).
- **Reveal** секций: opacity 0→1 / translateY 24→0, 500–700ms, stagger 80–120ms.
- **Карточки категорий:** hover-подъём 6–8px, смещение фото, зелёный radial под фото, стрелка.
- **Mobile:** hero статичный + лёгкий reveal, **без параллакса**.
- Обязателен `prefers-reduced-motion` fallback. Не анимируем текст hero/CTA/цены.

## 5. Интеракции и микрокопи
- Слайдер hero: переключение категорий (стрелки/точки/свайп), автопрокрутка опц. (пауза при
  наведении/фокусе).
- Карточки категорий/хитов кликабельны; «В корзину» из хита → тост + count-pulse.
- «Получить консультацию» / «Консультация в MAX» → форма/deep-link.
- Тексты — реальные RU; цифры магазина и «эксперты онлайн» — **placeholder до данных**.

## 6. Адаптив
Hero: desktop — 2 зоны (текст | инструмент), mobile — стек (текст над/под фото, статично).
Категории: 6→3→2 в ряд. Хиты — карусель со свайпом на mobile. Проверить **320/360/390/768/
1440**; CTA hero ≥44px; карточки не ломаются на 320.

## 7. Доступность
- Слайдер hero: доступен с клавиатуры (стрелки), кнопки слайдов с подписями, автопрокрутка
  останавливается при фокусе/наведении и по `prefers-reduced-motion`; текущий слайд — `aria`.
- Иерархия заголовков (один H1 — заголовок hero); декоративные SVG/частицы — `aria-hidden`.
- Контраст текста поверх hero-фото — AA (подложка/затемнение под текстом при необходимости).
- Карточки — доступные ссылки; статус наличия цвет+иконка+текст; фокус виден; тач ≥44.

## 8. Измеримость
| Событие | Триггер |
|---|---|
| `view_promotion` | показ hero/баннера |
| `hero_slide` | переключение слайда категории |
| `select_category` | клик по карточке категории |
| `select_item` / `add_to_cart` | хиты |
| `consult_click` | «Консультация в MAX»/«Получить консультацию» |
| `newsletter_submit` | подписка |
Guardrail: bounce с главной; доля ушедших в каталог/поиск.

## 9. Acceptance criteria (Главная)
- [ ] Hero ≥4 слоя (фон/чертёж/инструмент/текст), слайдер категорий; параллакс только
      desktop ≥1024; mobile — статичный hero.
- [ ] `prefers-reduced-motion`: без параллакса/3D, reveal → fade без сдвига.
- [ ] Reveal/hover ограничены; текст hero, CTA, цены не анимируются.
- [ ] Категории и хиты — единый шаблон; наличие = цвет+иконка+текст.
- [ ] Цифры магазина / «эксперты онлайн» / сроки — placeholder до подтверждения данными.
- [ ] Loading (скелетоны секций) и посекционный error/retry присутствуют.
- [ ] Контраст текста на hero AA; слайдер доступен с клавиатуры; декор `aria-hidden`.
- [ ] Изображения webp/avif, preload только hero, lazy ниже; CLS не растёт (aspect-ratio).
- [ ] Токены `design.md`; адаптив 320/360/390/768/1440.
