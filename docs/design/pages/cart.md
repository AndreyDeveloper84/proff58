# Постраничное ТЗ — Корзина · Wave 1

Детализация экрана к контракту `../tz-master.md` и `../../design.md` (токены §9).

---

## 1. Назначение и место в флоу
**Цель экрана:** дать проверить состав и итоговую цену и **перейти к оформлению**.
Откуда: PDP («В корзину»), мини-корзина в шапке, «Купить в 1 клик» (минуя корзину — в checkout).
Ведём к: **Checkout** (B2C оплата / B2B «Запросить счёт»). Побочно — «Продолжить покупки».
Ключевое: корзина **честно** показывает актуальные наличие и цену (из 1С) и не «плывёт».

## 2. Раскладка (зоны)
**Desktop (≥1024):** 2 колонки — **список строк** (лево) | **сводка заказа** (право, sticky
~360px: итог, скидки, доставка/самовывоз, CTA). Ниже — «С этим товаром покупают».
**Mobile (≤640):** список строк стеком; **сводка + «Оформить заказ» закреплены снизу**
(sticky bar: итог + CTA), детали сводки — раскрывающийся блок.

## 3. Блоки и компоненты

### 3.1 Строка товара
Фото (1:1, мелкое) · название (ссылка на PDP) · бренд · артикул · **цена за единицу** ·
**степпер количества** (с ограничением по остатку) · **сумма строки** (tabular-nums) ·
удалить (крестик/иконка) · **статус наличия построчно** (в наличии/мало/под заказ/нет).

### 3.2 Сводка заказа
Товары (N шт) · сумма · скидка · **способ получения** (самовывоз бесплатно / доставка —
оценка) · **итого** (крупно). **B2B (авторизован):** суммы с пометкой «с НДС» + CTA
«Запросить счёт» вместо оплаты. **Гость/B2C:** «Оформить заказ».

### 3.3 Действия
CTA «Оформить заказ» (primary) · «Продолжить покупки» (ghost) · «Очистить корзину» (link/danger,
с подтверждением). Кросс-сейл «С этим товаром покупают» (единый шаблон карточки).

## 4. Состояния (обязательные фреймы)

| Состояние | Что показываем |
|---|---|
| **Loading** | скелет строк + скелет сводки |
| **Заполненная** | строки + сводка + CTA |
| **Пустая** | иллюстрация/иконка + «В корзине пока пусто» + «Перейти в каталог» (+ хиты/недавние) |
| **Цена изменилась** | плашка на строке/в сводке «Цена обновилась: было → стало», **явное подтверждение** перед переходом; не пересчитываем молча |
| **Частичная доступность** | недоступные строки помечены (приглушены + «нет в наличии»); в сводке — «Оформить доступное» / «Убрать недоступные» |
| **Позиция закончилась** | строка «Нет в наличии» → предложить удалить/уведомить; блокирует общий CTA до решения |
| **Кол-во > остатка** | степпер ограничивает + подсказка «Доступно N шт» |
| **Гость vs B2B** | B2B — суммы «с НДС» + «Запросить счёт»; гость — розница + «Оформить» |
| **Error/retry** | «Не удалось обновить корзину. Повторить» |

## 5. Интеракции и микрокопи
- Изменение количества → пересчёт суммы строки и итога (значения обновляются, **не прыгают
  макетом**; число меняется, layout стабилен), озвучка `aria-live`.
- Удаление строки → **с возможностью отмены** («Товар удалён · Вернуть», тост ~5 сек).
- Цена изменилась → плашка + кнопка «Принять новую цену» перед оформлением.
- Частичная доступность → выбор «Оформить доступное»/«Убрать недоступные».
- Тексты кнопок = результат: «Оформить заказ», «Запросить счёт», «Продолжить покупки»,
  «Убрать недоступные», «Вернуть».

## 6. Адаптив
Desktop 2 колонки (список | sticky-сводка); tablet/mobile — стек + **sticky bottom-bar**
(итого + «Оформить»). Строка на mobile — компактная (фото слева, управление под ценой).
Проверить **320/360/390/768/1440**; степпер и «удалить» — тач ≥44px.

## 7. Доступность
- Степпер: кнопки с подписями (`aria-label` «увеличить/уменьшить»), поле числовое, значение
  озвучено; «удалить» — с явным `aria-label` (название товара).
- Итоги и суммы строк — `aria-live="polite"` при пересчёте.
- Подтверждение «очистить корзину» / удаление — доступный диалог (focus trap, Escape).
- Статус наличия построчно = цвет+иконка+текст; контраст AA; фокус виден.

## 8. Моушн (спокойный)
Плавное удаление строки (collapse), обновление сумм — без резких скачков. Тост отмены.
Итоговая сумма не анимируется «крутилкой» (стабильность цены). Reduced-motion — мгновенно.

## 9. Измеримость
| Событие | Триггер |
|---|---|
| `view_cart` | открытие корзины |
| `cart_update_qty` | изменение количества |
| `cart_remove` / `cart_undo` | удаление/возврат |
| `price_change_shown` / `price_change_accepted` | плашка цены/подтверждение |
| `begin_checkout` | «Оформить заказ» |
| `b2b_invoice_requested` | «Запросить счёт» (B2B) |
Guardrail: доля брошенных корзин; частота «цена изменилась».

## 10. Acceptance criteria (Корзина)
- [ ] Пустая корзина — приглашение в каталог (не тупик).
- [ ] Цена изменилась → плашка было→стало + подтверждение; молча не пересчитываем.
- [ ] Частичная доступность → пометка + «оформить доступное»/«убрать недоступные».
- [ ] Наличие построчно = цвет+иконка+текст; степпер ограничен остатком.
- [ ] Итоги стабильны (layout не прыгает), обновление озвучено `aria-live`.
- [ ] Удаление с отменой (undo-тост).
- [ ] B2B: суммы «с НДС» + «Запросить счёт»; гость — розница + «Оформить».
- [ ] Loading/error/retry присутствуют.
- [ ] Mobile: sticky bottom-bar (итого + CTA); тач ≥44; адаптив 320/360.
- [ ] Токены `design.md`; цены tabular-nums; моушн спокойный, reduced-motion.
