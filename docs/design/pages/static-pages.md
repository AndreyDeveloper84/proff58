# Постраничное ТЗ — Статические страницы (шаблон + 6) · Wave 1

Детализация к контракту `../tz-master.md` и `../../design.md` (токены §9). Почти весь объём —
**один контентный шаблон**; отдельные страницы отличаются наполнением (§3).

---

## 1. Назначение
Трастовый и справочный контент, на который ссылаются шапка/подвал: **Акции, Доставка и
оплата, Гарантия, Сервис, Компания, Контакты**. Цель — дать понятную информацию и мягко
увести в каталог/консультацию (без давления).

## 2. Единый шаблон контентной страницы

**Раскладка:** хлебные крошки → **H1** → лид-абзац → (опц. оглавление/якоря для длинных) →
контентные секции (заголовок + текст/список/таблица/иконки) → **CTA-блок «Консультация в
MAX»/«В каталог»** → подвал. Контент-колонка ≤ ~800px для читабельности; на desktop возможна
боковая мини-навигация по якорям.

**Общие состояния:** loading (скелет заголовка+абзацев), error/retry, пустой раздел (где
применимо — напр. нет акций). Реальный текст, не lorem.

**Общая доступность/адаптив:** иерархия заголовков (один H1, логичные H2/H3), таблицы с
заголовками (`<th>`, scope), контраст AA, фокус, тач ≥44; одна колонка на mobile, таблицы —
горизонтальный скролл/адаптив; проверить 320/360/390/768/1440. Моушн — только мягкий reveal,
reduced-motion fallback. Токены `design.md`.

## 3. Наполнение конкретных страниц

### 3.1 Акции
Сетка/список акционных карточек (баннер + условия + срок) → переход в PLP акции/на товар.
Состояния: список акций / **пустое** («Сейчас активных акций нет» + в каталог) / истёкшая
акция. Сроки — реальные; без ложных таймеров (этика).

### 3.2 Доставка и оплата
Секции: **самовывоз** (адрес/режим/бесплатно) · **доставка по Пензе и области** (зоны/сроки/
стоимость — таблица) · **[СДЭК/Почта по РФ — Wave 3, placeholder]** · **способы оплаты** (карта/
СБП/наличные/счёт юрлицу). Иконки способов. Данные о зонах/стоимости — placeholder до
подтверждения.

### 3.3 Гарантия
Условия гарантии, сроки, что входит/не входит, порядок обращения, ссылка на сервис. Возможен
аккордеон вопросов.

### 3.4 Сервис
Сервисный центр: услуги, адрес/режим, как сдать в ремонт, статус ремонта (если есть). CTA
консультации.

### 3.5 Компания (о нас)
История, миссия, цифры (10+/20000+/… — **placeholder**), фото магазина/команды, преимущества,
реквизиты. Ссылки на Контакты/Гарантию.

### 3.6 Контакты
**Адрес + карта** (статичная стилизованная, Wave 1) · телефоны · режим работы · e-mail ·
**реквизиты** (для юрлиц) · «как добраться» · опц. форма обратной связи (имя/телефон/сообщение
+ согласие ПДн). Состояния формы: валидация/успех/ошибка. Кнопки «Позвонить»/«Построить
маршрут» на mobile.

## 4. Измеримость (лёгкая)
| Событие | Триггер |
|---|---|
| `view_static_page` (page=…) | открытие страницы |
| `consult_click` | CTA консультации |
| `contact_submit` | отправка формы (Контакты) |
| `promo_click` | клик по акции |
Guardrail: доля отказов; переходы в каталог/консультацию.

## 5. Acceptance criteria (статические)
- [ ] Единый шаблон (крошки/H1/лид/секции/CTA); реальный RU-текст, не lorem.
- [ ] Каждая страница закрывает свои состояния (пустые акции, форма Контактов: валидация/успех/
      ошибка, loading/error).
- [ ] Таблицы (доставка/оплата) доступны (`<th>`/scope) и адаптивны на mobile.
- [ ] Данные о зонах/стоимости/цифрах — placeholder до подтверждения; без ложных сроков/таймеров.
- [ ] Карта в Контактах — статичная стилизованная (Wave 1).
- [ ] Форма Контактов: label/aria-invalid, согласие ПДн явное; тач ≥44.
- [ ] Иерархия заголовков, контраст AA, фокус; адаптив 320/360; токены `design.md`.
- [ ] CTA «Консультация в MAX»/«В каталог» на всех; моушн мягкий, reduced-motion.

## 6. Открытые вопросы (для этих страниц)
1. Финальные тексты: доставка (зоны/стоимость), гарантия, оферта/ПДн — от бизнеса.
2. Форма обратной связи в Контактах — нужна на Wave 1 или только телефон/адрес?
3. Реальные цифры и фото для «Компания»/«О магазине».
4. Акции — есть ли механика на бэке (карточки/сроки) на запуск или страница-заглушка?
5. Карта — статичная картинка или встраиваемая (2ГИС/Я.Карты) уже на Wave 1?
