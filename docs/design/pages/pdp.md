# Постраничное ТЗ — PDP (карточка товара) · Wave 1

Детализация экрана к контракту `../tz-master.md` (UX+фазы) и `../../design.md` (токены §9).
Здесь — что нарисовать конкретно на PDP: зоны, компоненты, все состояния, интеракции,
адаптив, доступность, моушн, метрики, приёмка.

---

## 1. Назначение и место в флоу
**Цель экрана:** дать пользователю решиться и **добавить товар в корзину** (или запросить
консультацию/счёт). Откуда приходят: PLP, поиск, «с этим покупают», прямая ссылка, MAX.
Ведём к: Корзина / Checkout (Купить в 1 клик) / Консультация в MAX.
Главный конверсионный элемент — **buy-box** (наличие + цена + «В корзину»), он всегда на виду.

## 2. Раскладка (зоны)
**Desktop (≥1024):** 2 колонки в верхнем экране — **галерея** (лево, ~58%) | **buy-box**
(право, ~380px, sticky при скролле на ≥1200). Ниже, на всю ширину: название/бренд/рейтинг →
ключевые ТТХ → табы → таблица ТТХ → «С этим товаром покупают» → преимущества → баннер
консультации.
**Mobile (≤640):** одна колонка, порядок: крошки → галерея → название/бренд/рейтинг → наличие
→ цена → ключевые ТТХ → табы/аккордеон → кросс-сейл → …; **buy-CTA закреплён снизу**
(sticky bottom-bar: цена + «В корзину»).

> **Порядок H1 (SEO/семантика).** В **DOM**: крошки → **H1/бренд/рейтинг/артикул** →
> галерея+buy-box (H1 в верхней смысловой зоне, не после галереи). **Visual desktop** допускает
> H1 в левой колонке над галереей. **Mobile** — H1 после галереи (как в порядке выше). Так не
> теряем SEO/семантику и не ломаем mobile-flow.

## 3. Блоки и компоненты

### 3.1 Хлебные крошки
Категорийный путь + название товара (последний — не ссылка). Мобайл — сокращать средние.

### 3.2 Галерея
Миниатюры (слева на desktop / точки-карусель на mobile) + основное фото 1:1; **зум по
наведению/тапу**; поверх фото — бейджи (−%/Хит/Новинка). Видео и 360° — **опционально, если
есть ассеты** (иначе не показываем плейсхолдер-заглушку под видео). Кнопка «наведите для
увеличения» / полноэкранный просмотр.

### 3.3 Заголовок · бренд · рейтинг · артикул
H1 (название), логотип/имя бренда, звёзды + число отзывов (**Wave 1 — если отзывов нет,
блок рейтинга скрываем**, не рисуем «0 отзывов» как тупик), артикул (utility, tabular-nums).

### 3.4 Buy-box (главный блок покупки)
Сверху вниз: **статус наличия** (цвет+иконка+текст, см. §4) + строка получения (самовывоз/
доставка) → **блок цены** (текущая крупно, старая зачёркнута, скидка/экономия). **Цена единая
для всех — отдельной B2B-цены нет.** НДС для юрлиц не показывается на PDP; он выделяется в
стоимости корзины/счёта (см. `cart.md`/`checkout.md`, «в т.ч. НДС 20%»). Далее: гарантия →
**степпер + «В корзину»** → **«Купить в 1 клик»** (контракт — §3.10) → [сравнить/избранное —
Wave 2, на Wave 1 скрыто или неактивно] → блок **«Консультация в MAX»** (живой менеджер, не
AI; кнопка + микротекст «Поможем подобрать под задачу»).

### 3.5 Ключевые характеристики
Сетка 4–6 иконок с ключевыми ТТХ (мощность, энергия удара, патрон, Ø, режимы, вес),
«Все характеристики →» (якорь к таблице/таб).

### 3.6 Табы / аккордеон
Характеристики · Описание · Комплектация · Доставка и оплата · **Отзывы [Wave 2 — таб
скрыт/неактивен на Wave 1]**. Desktop — табы, mobile — аккордеон. Активный таб — подчёркивание
`--color-action`.

### 3.7 Таблица характеристик
2 колонки, зебра (`--surface`), ключ `--text-secondary` / значение вес 500, единицы —
tabular-nums. «Показать все» если длинная.

### 3.8 «С этим товаром покупают»
Карусель из **единого шаблона карточки** (§ tz-master 2.4). Не смешивать с другими шаблонами.

### 3.9 Преимущества покупки + баннер консультации
Ряд из 5 иконок (гарантия/доставка/самовывоз/сервис/оплата) + баннер «Не знаете, какой
инструмент выбрать?» с экспертом и кнопкой «Консультация в MAX».

### 3.10 «Купить в 1 клик» — контракт
PDP → **Checkout с одним товаром, qty=1** → контакты + способ получения + оплата (бронь 15 мин
при онлайн-оплате). Если товар **уже в корзине** — **не смешиваем** автоматически: оформляем
только этот товар, подпись «Оформляем только этот товар». Наличие/цена пере-проверяются при
входе в checkout. Для B2B — тот же путь, финальный CTA «Запросить счёт».

## 4. Состояния (обязательные фреймы)

| Состояние | Что показываем | CTA |
|---|---|---|
| **Loading** | скелетоны: галерея + buy-box + строки ТТХ | — |
| **В наличии (N)** | «● В наличии · N шт», самовывоз сегодня | «В корзину» (активна) |
| **Мало (≤ порог)** | «● Осталось N шт» (янтарный) | «В корзину» |
| **Под заказ** | «◷ Под заказ · ~X дн», «сообщим в MAX» | «Под заказ» |
| **Нет в наличии** | «○ Нет в наличии», приглушённое фото | «Уведомить о поступлении» |
| **Цена изменилась** | плашка при возврате из корзины/по push — «Цена обновилась: было→стало» | подтверждение |
| **Гость** | единый ценник; обычные CTA | «В корзину» / «Купить в 1 клик» |
| **B2B (авторизован)** | тот же ценник (НДС выделяется в корзине/счёте, не на PDP); путь счёта — через checkout | + «Купить в 1 клик» → «Запросить счёт» |
| **Error/retry** | товар не загрузился → «Не удалось загрузить. Повторить» | retry |
| **Товар не найден** | 404-товара → предложить категорию/поиск/похожие | — |

Отзывов нет → таб «Отзывы» скрыт (Wave 2). Видео/360 нет → только фото.
**Контентная деградация:** нет фото → фирменный placeholder товара (без fake-изображения);
нет части ТТХ → не рисуем пустые строки; нет описания → скрываем таб «Описание».

## 5. Интеракции и микрокопи
- «В корзину» → тост «Товар в корзине» + count-pulse счётчика в шапке; кнопка короткий bounce.
- Смена фото галереи, зум (hover/тап), полноэкранный просмотр по клику.
- Раскрытие таба/аккордеона; «Все характеристики» — плавный скролл к таблице.
- «Уведомить о поступлении» → **телефон + имя** (без обязательного MAX) + опция «Сообщить в
  MAX»; подтверждение «Сообщим, когда товар появится».
- «Консультация в MAX» → deep-link; микротекст без обещаний-плейсхолдеров (число экспертов —
  placeholder до подтверждения данными).
- Кнопка = результат: «В корзину», «Купить в 1 клик», «Запросить счёт», «Уведомить о поступлении».

## 6. Адаптив
Рисовать **1440 / 768 / 390**; карточки кросс-сейла проверить на **320/360** (2 кол, длинные
цены, CTA ≥44px). Desktop ≥1200 — sticky buy-box; mobile — sticky bottom-bar (цена + «В
корзину»), галерея-карусель с точками, табы → аккордеон.

## 7. Доступность
- Галерея: клавиатурная навигация миниатюр (стрелки), `alt` у фото, зум доступен с клавиатуры,
  фокус виден; полноэкранный просмотр — focus trap + Escape.
- Табы: роль `tablist/tab/tabpanel`, roving tabindex, стрелки переключают.
- Статус наличия = цвет + иконка + текст (не только цвет). Контраст AA. Тач ≥44px.
- Тосты/счётчик — `aria-live="polite"`. Формы «Уведомить» — `aria-invalid`, привязка ошибки.
- `prefers-reduced-motion`: отключить bounce/зум-анимации, оставить мгновенную смену.

## 8. Моушн (спокойный — PDP не wow-зона)
Hover: лёгкий zoom фото, bounce кнопки корзины. **Без параллакса.** Reveal нижних блоков —
мягкий, без сдвига цен/CTA. Всё уважает reduced-motion (`design.md` §17).

## 9. Измеримость
| Событие | Триггер |
|---|---|
| `view_item` | открытие PDP |
| `add_to_cart` | «В корзину» |
| `buy_one_click` | «Купить в 1 клик» |
| `notify_subscribe` | «Уведомить» (нет в наличии) |
| `b2b_invoice_requested` | «Запросить счёт» (B2B, через checkout) |
| `consult_click` | «Консультация в MAX» |
Guardrail: доля PDP без `add_to_cart`; ошибки галереи.

## 10. Acceptance criteria (PDP)
- [ ] Buy-box всегда доступен (sticky desktop ≥1200 / bottom-bar mobile), CTA не «прыгает».
- [ ] Все состояния наличия нарисованы; CTA меняется корректно; «нет» → «Уведомить».
- [ ] **Единый ценник для всех; отдельной B2B-цены нет; НДС — в корзине/счёте, не на PDP.**
- [ ] Наличие = цвет+иконка+текст; контраст AA; тач ≥44.
- [ ] Отзывы (Wave 2) — таб скрыт, без тупика «0 отзывов»; видео/360 — только при ассетах.
- [ ] Loading/error/retry/404-товара присутствуют.
- [ ] Галерея и табы доступны с клавиатуры (aria, focus trap, Escape).
- [ ] Кросс-сейл — единый шаблон карточки; адаптив 320/360/390/768/1440.
- [ ] Моушн спокойный, reduced-motion fallback; параллакса нет.
- [ ] Токены `design.md`, тёмная шапка/подвал; неподтверждённые данные — placeholder.
- [ ] **«Купить в 1 клик»** — контракт (qty=1, не смешивать с корзиной) нарисован.
- [ ] **«Уведомить»** = телефон+имя (без обяз. MAX) + опция «Сообщить в MAX».
- [ ] **Контентная деградация** (нет фото/ТТХ/описания) учтена; **H1 в DOM** в верхней зоне.
