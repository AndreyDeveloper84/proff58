# Постраничное ТЗ — PLP (категория / выдача) · Wave 1

Детализация экрана к контракту `../tz-master.md` и `../../design.md` (токены §9).
PLP = страница списка товаров категории и страница результатов поиска (различия — в §12).

---

## 1. Назначение и место в флоу
**Цель экрана:** быстро **отфильтровать каталог до нужного товара** и перейти в PDP.
Откуда: Каталог-мегаменю, хлебные крошки, поиск, «Хиты» с главной, прямая ссылка.
Ведём к: **PDP** (клик по карточке) или сразу «В корзину» из карточки.
Ключевой конверсионный принцип (из инфографики «быстрое сканирование»): **единый шаблон
карточки** → пользователь сканирует по одной схеме → выше конверсия.

## 2. Раскладка (зоны)
**Desktop (≥1024):** крошки → H1 категории + количество → (опц. hero-баннер категории) →
**тулбар** (сортировка + переключатель вид сетка/список + счётчик найденного) → 2 колонки:
**сайдбар фасетов** (лево, sticky 264–280px) | **сетка карточек** (право). Внизу — «показать
ещё» + crawlable пагинация + SEO-текст.
**Mobile (≤640):** крошки → H1 + количество → строка «[Фильтры ▾ N] [Сортировка ▾]» (фасеты
и сортировка — в drawer/bottom-sheet) → сетка 2 колонки → «показать ещё».

## 3. Блоки и компоненты

### 3.1 Хлебные крошки + H1 + количество
Путь по дереву; H1 = название категории; рядом «N товаров» (tabular-nums, обновляется при
фильтрации).

### 3.2 Hero-баннер категории (опционально)
Если у категории есть баннер (существующий функционал) — компактный блок под крошками; без
него секцию не рисуем (не оставляем пустоту).

### 3.3 Тулбар
- **Сортировка:** популярность (по умолч.) / цена ↑ / цена ↓ / рейтинг / новизна.
- **Вид:** сетка ↔ список (список — расширенная строка с ТТХ; опц., по умолчанию сетка).
- Счётчик «Показано X из N».

### 3.4 Сайдбар фасетов (EAV, со счётчиками)
Группы (порядок — по важности, уточнить §11): **Цена** (двойной слайдер + поля «от/до»),
**Наличие** (в наличии / под заказ), **Бренд**, **Мощность**, **Энергия удара**, **Тип
патрона**, **Назначение**, и др. атрибуты категории. У каждого значения — счётчик `(124)`.
Активные фильтры — **чипами** над сеткой (`--green-tint`, крестик) + «Сбросить всё».
Свернуть/развернуть группы; «Показать ещё» для длинных списков значений.

### 3.5 Сетка карточек
**Единый шаблон** (tz-master §2.4): фото→бренд→название→рейтинг→наличие→цена→«В корзину».
**Не смешивать шаблоны** — в одной сетке все карточки одного шаблона и **одной высоты** в
строке; не допускается мешать вертикальные и горизонтальные карточки. Колонки: mobile 2 ·
lg 3–4 · xl 4–5.

### 3.6 Пагинация / подгрузка — **гибрид (решено)**
- Основной UX: кнопка **«Показать ещё 24 товара»**.
- SEO/fallback: **crawlable якорная пагинация** снизу (`1 2 3 … 21`).
- URL меняется/сохраняется так, чтобы можно было вернуться назад к позиции.
- **Бесконечный скролл без якорей — запрещён.**

### 3.7 SEO-текст
Опциональный текстовый блок внизу категории (сворачиваемый).

## 4. Состояния (обязательные фреймы)

| Состояние | Что показываем |
|---|---|
| **Loading** | скелет-сетка карточек + скелет фасетов; счётчик «загрузка» |
| **Базовое (есть товары)** | сетка + активные фасеты + счётчик |
| **Empty (0 по фильтру)** | «Ничего не найдено под выбранные фильтры» + **«Сбросить фильтры»** + показать ближайшее/популярное |
| **Пустая категория** | «В этой категории пока нет товаров» + ссылки на соседние |
| **Много активных фильтров** | ряд чипов переносится/сворачивается «+N», «Сбросить всё» |
| **Error/retry** | «Не удалось загрузить список. Повторить» |
| **Наличие в карточках** | в наличии / мало / под заказ / нет — по каждой карточке (цвет+иконка+текст) |
| **Подгрузка (loading more)** | скелет-строка под сеткой при «Показать ещё» |

## 5. Интеракции и микрокопи
- Применение фасета → сетка и счётчик обновляются **без полной перезагрузки**; число
  результатов озвучивается `aria-live`.
- Чип фильтра: крестик снимает; «Сбросить всё» очищает разом.
- Слайдер цены: тянется + ручной ввод «от/до»; применение по отпусканию/Enter.
- Сортировка/вид: мгновенно пересобирают сетку (без прыжка скролла к верху без нужды).
- Mobile: «Фильтры» открывают drawer; кнопка «Показать N товаров» внизу drawer применяет.
- Карточка: hover фото/кнопка, «В корзину» → тост + count-pulse (без прыжков цены).
- Тексты: «Показать ещё 24 товара», «Сбросить фильтры», «Показать N товаров».

## 6. Адаптив
Сетка карточек 2 (mobile) / 3–4 (lg) / 4–5 (xl); проверить **320/360/390/768/1440**. Фасеты:
desktop — sticky-сайдбар; mobile/tablet — **drawer** с кнопкой применения. Сортировка на
mobile — bottom-sheet. Тач ≥44px, карточки не ломаются на 320.

## 7. Доступность
- Фасеты: группы чекбоксов с подписями (`fieldset/legend`), клавиатурная навигация, слайдер
  цены управляем с клавиатуры (стрелки), значения озвучены.
- Счётчик результатов и «найдено N» — `aria-live="polite"` при каждом изменении фильтра.
- Drawer фасетов (mobile): focus trap + закрытие по Escape, возврат фокуса на кнопку «Фильтры».
- Карточка — доступная ссылка + отдельная кнопка корзины; статус наличия цвет+иконка+текст.
- Контраст AA; видимый фокус; тач ≥44.

## 8. Моушн (спокойный)
Hover карточек (подъём/zoom фото/стрелка — по `design.md` §9). Reveal сетки при скролле —
мягкий, без сдвига цен. Скелетоны — shimmer, уважает reduced-motion. **Без параллакса.**

## 9. Измеримость
| Событие | Триггер |
|---|---|
| `view_item_list` | открытие PLP/выдачи |
| `filter_apply` | применение фасета |
| `sort_change` | смена сортировки |
| `select_item` | клик по карточке → PDP |
| `add_to_cart` | «В корзину» из карточки |
| `load_more` / `pagination` | подгрузка/страница |
Guardrail: доля выдач с 0 результатов (empty), глубина фильтрации без перехода в PDP.

## 10. Acceptance criteria (PLP)
- [ ] Единый шаблон карточки во всей сетке; наличие = цвет+иконка+текст.
- [ ] **Запрет смешивания шаблонов карточек** (mobile и desktop): один шаблон, одна высота в
      строке; не мешать вертикальные/горизонтальные.
- [ ] Все фасеты со счётчиками; активные — чипами + «Сбросить всё».
- [ ] Empty (0 по фильтру) и пустая категория нарисованы, ведут дальше (reset/соседние).
- [ ] Loading (скелет-сетка), loading-more, error/retry присутствуют.
- [ ] Сетка адаптируется 2/3/4/5; карточки целы на 320/360.
- [ ] Mobile: фасеты в drawer (focus trap/Escape), сортировка — sheet, кнопка «Показать N».
- [ ] Счётчик результатов и фильтрация озвучены `aria-live`; фасеты доступны с клавиатуры.
- [ ] **Пагинация — гибрид: «Показать ещё» + crawlable якорная пагинация**; URL для возврата;
      бесконечный скролл без якорей запрещён.
- [ ] Токены `design.md`; моушн спокойный, reduced-motion; без параллакса.
- [ ] Цены tabular-nums; неподтверждённые данные — placeholder.

## 12. Отличия «Поиск/выдача» от «Категории»
Та же раскладка/карточки/фасеты, но: **нет дерева категории**, заголовок «Найдено N по
“запрос”», подсказки в поле поиска (товары/категории/бренды), **empty**: «Ничего не нашли по
“…”. Проверьте артикул или сбросьте фильтры» + популярное/похожее. Поиск по артикулу/модели/
бренду. (Отдельная детализация — `search.md`.)
