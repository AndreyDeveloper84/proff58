# ТЗ дизайнеру — витрина «Профессионал — территория инструмента»

Бриф на отрисовку макетов магазина в **светлой теме «Чистая мастерская»**. Документ опирается
на 3 утверждённых ИИ-макета (главная, PDP, паттерн карточки) и на дизайн-систему `../../design.md`
(она — **источник истины** по токенам, типографике, состояниям). Здесь — что и как нарисовать
по каждому экрану, включая страницы, которых ещё нет в макетах.

> **Главный принцип:** дорогой технический wow на 1-м экране и баннере консультации; дальше —
> спокойный магазин, где сразу видно каталог, цену, наличие и кнопку «купить». Зелёный — сигнал
> действия, не заливка. Подробности моушна — `design.md` §17.

**Сверки макетов с дизайн-системой (учесть при отрисовке):**
1. **Зелёный CTA.** В макетах CTA сделан ярким средне-зелёным. Брать из токенов: база
   `--green-700 #097A3C` для кнопок/ссылок (белый текст — контраст AA). Изумруд `--green-500`
   — лого/иконки/крупный акцент, **не** мелкий текст на белом. Если бренд-зелёный из макета
   ярче — закрепить как `--green-600/500`, но CTA-кнопка обязана проходить AA (white/зелёный ≥ 4.5).
2. **B2B-цена** показывается отдельной строкой «Цена для юр. лиц · с НДС» — слот обязателен
   в блоке цены всегда (скрыт для розницы, виден юрлицу).
3. **Тёмная шапка/подвал** — обязательны (преемственность визитки), левый край шапки —
   «инструментальный кант» (signature, `design.md` §10).

## 1. Общие правила (для всех экранов)

- **Сетка:** контейнер 1320px, 12 колонок, gutter 24. Боковые поля 16 (моб) → 24 → 32.
- **Брейкпоинты:** 640 / 768 / 1024 / 1280 / 1536. Рисовать минимум **desktop 1440** и
  **mobile 390**; для ключевых экранов — ещё **tablet 768**.
- **Токены/типографика/тени/радиусы** — строго по `design.md` §2–5. Заголовки — display
  КАПС (Oswald/Saira Condensed), тело — Inter, цены/артикулы — tabular-nums.
- **Каждый экран = контракт состояний** (`design.md` §8): обязательно нарисовать
  **loading (скелетоны), empty, error, offline** и доменные состояния (нет в наличии / под
  заказ / цена изменилась / гость↔B2B / частичная корзина / резерв 15 мин истёк).
- **Доступность:** контраст AA, видимый фокус, тач-таргет ≥ 44px, статус = цвет + иконка +
  текст, уважать `prefers-reduced-motion`. Реальный текст, не lorem.
- **Моушн:** wow только hero + баннер консультации; reveal-блоки `opacity 0→1 / translateY
  24→0`, 500–700ms, stagger 80–120ms; product-карточки — спокойные (hover фото/кнопка). Цены,
  CTA, поиск, корзина не «летают». Параллакс только desktop ≥ 1024, mobile — статичный hero.
- **Чего НЕ делать:** тёмная вся страница, неон, искры/дым в каждом блоке, анимация цен/CTA,
  автоплей тяжёлого видео, 3D без fallback, переизбыток зелёного.

## 2. Глобальные компоненты (рисуем один раз, переиспользуем)

### 2.1 Шапка (тёмная, sticky)
Два уровня. **Верх:** лого + «Инструментальный кант» слева, кнопка **«Каталог товаров»**
(зелёная), крупный поиск по каталогу, выбор города (Пенза ▾), телефон + режим работы,
иконки **Избранное / Сравнение / Корзина** (со счётчиками). **Низ-навбар:** Акции · Доставка
и оплата · Гарантия · Сервис · Компания · Контакты + кнопка **«Консультация в MAX»**.
Состояния: счётчики 0/N, sticky-сжатие при скролле, мобайл — бургер + поиск-иконка +
корзина, нижняя таб-бар опционально.

### 2.2 Подвал (тёмный)
Колонки: Полезные советы (подписка e-mail) · Каталог · Покупателям · Компания · Контакты.
Соцсети, **иконки оплаты** (карты/СБП/ЮKassa/счёт юрлицу), правовые ссылки, копирайт.

### 2.3 Каталог-мегаменю
Дерево категорий (3 уровня), превью-картинки разделов, популярные подкатегории, промо-слот.
Состояния: hover-раскрытие, мобайл — полноэкранный drawer с аккордеоном.

### 2.4 Карточка товара — ЕДИНЫЙ шаблон (по `fast_eye_scan.png`)
Жёсткая структура сверху вниз, **одинаковая во всех сетках** (не смешивать шаблоны):
**фото (1:1) → бренд → название (2 строки clamp) → рейтинг (звёзды + кол-во) → наличие
(зелёная точка + текст) → цена (крупно, старая зачёркнута) → кнопка корзины**. Поверх фото:
бейджи **Хит / −%**, иконки **избранное (♥)** и **сравнение**. Hover: лёгкий подъём, zoom
фото, bounce кнопки корзины (без прыжков цены/текста). Варианты: в наличии / мало / под
заказ / нет (CTA → «Уведомить»), скелетон.

### 2.5 Бейдж наличия, блок цены, степпер, хлебные крошки, тосты, AI-консультант, MAX
По `design.md` §9 (статус наличия = цвет+иконка+текст; блок цены с B2B-слотом; степпер;
крошки; тост «добавлено в корзину»; AI-консультант как реальная панель «Спросить в MAX» —
в макете с маскотом-роботом, маскот опционален; «Отслеживать в MAX» deep-link).

## 3. Страницы

Для **каждой** страницы дизайнер сдаёт: desktop + mobile, все состояния, спецификацию
компонентов (отступы/токены), поведение моушна.

### 3.1 Главная — по `proff_light_theme.png`
Блоки сверху вниз:
1. **Hero-параллакс** (5 слоёв, слайдер категорий, точки 01–02–03): фон-мастерская blur →
   чертёжный SVG со схемой инструмента и метками (1000 об, 60 Гц, Ø…) → детали/маркеры →
   крупный реальный инструмент (3D от мыши) → текст «ПРОФЕССИОНАЛЬНЫЙ ИНСТРУМЕНТ / для тех,
   кто работает точно» + 4 УТП (гарантия / самовывоз сегодня / счёт для юрлиц / консультация)
   + CTA «Перейти в каталог» + «Получить консультацию». Стрелки слайдера.
2. **Категории-витрина** (6 карточек: Электроинструмент, Бензоинструмент, Садовая техника,
   Сварочное, Оснастка, Расходные — с количеством товаров, зелёная стрелка, hover-подъём).
3. **Хиты продаж** — карусель карточек (единый шаблон §2.4), «Смотреть все».
4. **Баннер консультации** — «Не знаете, какой инструмент выбрать?» + эксперт (фото),
   параллакс фона, CTA «Получить консультацию» + «Консультация в MAX» (pulse 1 раз), «24
   эксперта онлайн».
5. **Преимущества** (5 иконок: гарантия / быстрая доставка / самовывоз / сервис / удобная оплата).
6. **О магазине** — живая карта Пензы (пин, дорисовка маршрута), счёт цифр 10+ / 20 000+ /
   50 000+ / 100+, «Подробнее о компании».
7. **Подписка** + подвал.
Состояния: загрузка (скелетоны секций), reduced-motion (статичный hero, fade без сдвига).

### 3.2 Категория / PLP (нет в макетах — спроектировать)
Цель: отфильтровать до нужного. Блоки: хлебные крошки → H1 категории + кол-во → hero-баннер
категории (опц., из существующего функционала) → панель **сортировки** (популярность/цена↑↓/
рейтинг/новизна) + переключатель вид (сетка/список) → **сайдбар фасетов (EAV) со счётчиками**
(цена-слайдер, наличие, бренд, мощность, энергия удара, тип патрона, назначение; активные
чипы; «сбросить») → **сетка карточек** (lg 3–4 / xl 4–5; mobile 2; фасеты в drawer) →
подгрузка/пагинация. Состояния: **empty** (нет товаров под фильтр → «сбросить»), loading
(скелет-сетка), много активных фильтров, SEO-текст внизу.

### 3.3 Поиск / выдача (нет в макетах)
Поле в шапке: подсказки (товары/категории/бренды) в поповере, поиск по артикулу/модели/бренду.
Страница выдачи = PLP без дерева, с «Найдено N по “запрос”». **Empty:** «Ничего не нашли по
“…”. Проверьте артикул или сбросьте фильтры» + популярные/похожие. Перспектива — AI-подбор.

### 3.4 PDP — по `light_product.png`
Блоки: хлебные крошки → **галерея** (миниатюры + основное фото, бейджи −%/Хит, видео и 360°,
«наведите для увеличения») | **колонка покупки** (наличие: «в наличии >N», самовывоз
сегодня/бесплатно, доставка завтра; **цена + скидка + экономия**; **B2B-цена «с НДС»**;
гарантия; степпер; «В корзину»; «Купить в 1 клик»; сравнить/избранное; блок **AI-консультант**
«Нужна помощь с выбором?») → **название + бренд + рейтинг + артикул** → **ключевые ТТХ**
(сетка 6 иконок: мощность/энергия удара/сила удара/частота/режимы/патрон, «Все характеристики»)
→ **табы** (Характеристики / Описание / Комплектация / Доставка и оплата / Отзывы N) →
**таблица ТТХ** (2 колонки, зебра) → **«С этим товаром покупают»** (карусель) → преимущества
покупки (5) → баннер консультации → О магазине → подвал. Sticky buy-box на desktop ≥1200.
Состояния: все доменные (под заказ/нет в наличии → «Уведомить»; цена изменилась; гость↔B2B),
галерея loading, нет отзывов (empty-приглашение).

### 3.5 Корзина (нет в макетах)
Список строк (фото, название, артикул, цена, степпер, удалить, наличие построчно) → сводка
(итог, скидки, доставка/самовывоз) → CTA «Оформить заказ». Доменные: **частичная
доступность** (пометить недоступные, «оформить доступное»), **цена изменилась** (плашка
было→стало, подтверждение), пустая корзина (приглашение в каталог), гость↔B2B.

### 3.6 Оформление / Checkout (нет в макетах)
Шаги: контакты → способ получения (самовывоз из магазина — главный сценарий / зональная
доставка по Пензе / СДЭК-Почта по РФ) → оплата (**B2C:** ЮKassa карта/СБП/ЮMoney, наличными
при получении; **B2B:** безналичный счёт-PDF на юрлицо) → подтверждение. Показывать **бронь
15 мин** при онлайн-оплате. Состояния: ошибка оплаты, **резерв истёк (expired)**, валидация
полей, B2B-реквизиты юрлица. Авторизация/OTP — через **MAX** (request_contact + «скопировать
код»), не SMS.

### 3.7 Спасибо за заказ / Отслеживание (нет в макетах)
Подтверждение номера/суммы, статус, **обязательная кнопка-deep link «Отслеживать в MAX»**
(сохраняет `max_chat_id`, в т.ч. гостю), для B2B — ссылка на счёт-PDF. Человекопонятный
статус заказа (3 оси → 1 бейдж, `design.md` §9.3).

### 3.8 Кабинет B2C (нет в макетах)
Заказы (список + карточка заказа со статусом), повтор заказа, избранное, сравнение, профиль,
адреса, привязка MAX. Empty-состояния для пустых разделов.

### 3.9 Кабинет B2B (нет в макетах)
То же + юрлица/реквизиты, **счета-PDF**, история запросов счёта, B2B-цены, возможно несколько
юрлиц/доверенностей. Роль-зависимая цена видна везде.

### 3.10 Статические страницы (из навбара)
Акции · Доставка и оплата · Гарантия · Сервис · Компания (о нас) · Контакты (карта, реквизиты,
режим, как добраться). Единый шаблон контентной страницы (H1, лид, секции, CTA-консультация).

### 3.11 Системные
**404**, **500**, **offline-баннер**, страница «ничего не найдено», техработы. В стиле бренда,
с выходом в каталог/на главную.

## 5. Acceptance criteria для макетов

- [ ] Использованы только токены/стили из `design.md` (нет «случайных» hex вне палитры).
- [ ] Карточка товара — единый шаблон во всех сетках (фото→бренд→название→рейтинг→наличие→
      цена→CTA), шаблоны не смешаны.
- [ ] Контраст AA: CTA `--green-700` + белый текст; изумруд не для мелкого текста.
- [ ] Тёмная шапка/подвал + «инструментальный кант» присутствуют.
- [ ] Для каждого экрана нарисованы loading/empty/error + доменные состояния.
- [ ] Цена по роли: B2B-слот «с НДС» заложен везде, где есть цена.
- [ ] Наличие/статусы = цвет + иконка + текст.
- [ ] Mobile: hero статичный, фасеты в drawer, тач-таргеты ≥ 44px.
- [ ] Моушн ограничен (hero + баннер), reduced-motion fallback показан.
- [ ] Реальные тексты RU (не lorem), термины языком пользователя.
