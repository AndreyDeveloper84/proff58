# PARS-05 · Парсер · полный прогон и запись на staging

# WRITE по каталогу — строго по гейт-циклу.

## КОНТЕКСТ

Готово: парсер (`parser/`, два режима), карта (`scraped_attr_map.perforatory.json`),
импортёр (`catalog_import_scraped`), источник `scraper` с приоритетом **50**.

PARS-04 прогнал импортёр локально на выгрузке из 32 карточек: matched 16,
записано 55 PAV, идемпотентность подтверждена, `voltage` у сетевых не появился,
отпечаток неприкасаемых полей идентичен.

**Решение владельца 2026-07-28, действует по умолчанию:** при расхождении спарсенного
значения и regex-значения **прав производитель**. Такие расхождения записываются без
отдельного согласования, но **обязательно логируются** (товар, атрибут, было → стало,
поле источника). Прецедент: 44544 Ресанта П-32-1000К, `energy_impact` 5,5 → 5,2 —
подтверждено.

Порог сохраняется как индикатор **системной** ошибки: если расхождений больше ~10 % от
совпадений — это скорее дефект карты, чем массовая неправота названий; остановиться
и доложить.

## ЗАДАЧА 1 — СОБРАТЬ ПОЛНЫЙ ОБЪЁМ

Прогнать парсер (режим A, HTTP) по всем перфораторам четырёх источников:
`resanta.ru`, `vihr.su`, `interskol.ru`, `zubr.ru`.

Режим доступа — прежний и обязательный: `robots.txt`, **≤ 1 запрос в 2–3 с на хост**,
без параллелизма, честный `User-Agent` с контактом, кэш скачанного, журнал JSONL.
При 429/403 — **остановиться и доложить**, обходы не подбирать.

Ожидаемый порядок величины: у наших 188 перфораторов российские бренды покрывают
~40 позиций (замер Phase 1: 82 % совпадений на выборке из 49). Реальное число покажет
матчинг — важно не «побольше», а честно.

## ЗАДАЧА 2 — ЗАМЕР ДО ЗАПИСИ

`--dry-run` на полном объёме, с разбивкой:

- **create** — в пустые поля (главная цель: 55 перфораторов без `power`);
- **overwrite** — перезапись regex-значений: **перечислить поимённо**, товар / атрибут /
  было → стало / поле источника. Записываем по умолчанию, но список обязан быть в
  протоколе;
- **confirm** — совпадения, изменений нет;
- **skipped** — по приоритету и по правилу `voltage`;
- **ambiguous / not_found** — в отчёт, не в базу.

Сверить долю overwrite с порогом 10 %. Превышение — стоп и доклад.

## ЗАДАЧА 3 — ГЕЙТ-ЦИКЛ

Локально, затем **staging по отдельному GO владельца**:

read-only с отпечатком → preflight (нет `content_locked`, `manual`/`import_1c` в scope
не пострадают) → dry-run с предсказанием чисел **до** прогона → pg_dump → write одной
транзакцией → post-audit (отпечаток неприкасаемых полей идентичен, дублей PAV нет,
`attrs_cache` ≡ EAV по затронутым, повторный прогон даёт 0 записей) → **витрина живыми
запросами**.

## ЗАДАЧА 4 — ЧТО ПОЛУЧИЛ ПОКУПАТЕЛЬ

Показать эффект, а не только числа записи:

- сколько перфораторов получили `power`, `energy_impact`, `no_load_speed`, `chuck`;
- **работают ли фильтры** — счётчики фасетов до и после, на конкретных запросах;
- сколько товаров стало фильтруемо по мощности там, где раньше не было.

Это и есть смысл всей затеи: не «записали N значений», а «покупатель может выбрать
перфоратор по мощности».

## ГРАНИЦЫ

- Не трогать: цену, остаток, `code_1c`, `article`, `name`, дерево категорий,
  `tool_type`, значения `source="manual"`, `rules`, `import_1c`.
- Фотографии не берём.
- `voltage` пишется **только аккумуляторным** — правило из PARS-04.
- Новые `Attribute` / `AttributeOption` не создавать; несопоставленное — в отчёт.
- Контур `tool_type` (манифест, gate, ruleset) не трогать.
- Глобальные команды (`enrich_attributes` без `--path`, `rebuild_attrs_cache`) запрещены;
  кэш пересобирать точечно.
- Push и PR — только по явной просьбе владельца.
- **Перед любой работой с GitHub** — сначала `git fetch gitlab --prune` и сверка
  `origin/dev` с `gitlab/dev`.
- Рабочая копия общая: чужие изменения не откатывать, `git add` точечными путями.
- Параллельно идут TT-07 (манифест и seed опций) и CAT-05 (фасеты). На staging
  **write не выполнять одновременно** — свериться и согласовать порядок.
- Phase 6 (проверка витрины как отдельная фаза) и Phase 7 не начинать — доказательство
  эффекта входит сюда, но приёмку MVP не объявлять.

5. **`manual`, `rules`, `import_1c` не затёрты** — проверено выборкой.
