## 3. Ключевые находки

1. **Артикул производителя есть у всех четырёх источников**, но лежит в разных местах:
   JSON-LD `sku` (Ресанта, ВИХРЬ), HTML+payload `Артикул` (Интерскол), строка таблицы
   `Артикул` (ЗУБР).
2. **`article` у нас — три разных сущности одновременно:** код производителя (`75/3/2`),
   обозначение модели (`ЗП-28-800 К`) и внутренний код поставщика (`РСВ-…`).
3. **`РСВ-…` непригоден для матчинга**: 2817 товаров каталога, 577 групп дубликатов;
   один и тот же `РСВ-140807` висит на двух ВИХРЯХ и одном Интерсколе.
4. **Голый номер артикула Ресанты/ВИХРЯ неуникален между брендами**: `75/3/2` — Ресанта
   П-30-900К, `72/3/2` — ВИХРЬ П-900К. Только с префиксом бренда.
5. **Матчинг по модели даёт 40/49 (82%)** на пилотной выборке; ЗУБР — 18/26, остальное
   снято с производства (вся линейка SDS-Max `ЗПМ-*`).
6. **Подстрочный матч моделей опасен**: `ЗП-2680` — подстрока `ЗП-26-800`; наивное
   сравнение склеивает разные товары. Нужно строгое равенство нормализованных ключей.
7. **Мощности нет в таблице характеристик Ресанты** — единственный источник в карточке
   это краткая сводка «SDS-Plus, 900 Вт, …». У ВИХРЯ, ЗУБРа и Интерскола `Мощность` есть.
8. **`interskol.ru` структурно лучший источник** — свойства приходят готовым JSON со
   стабильными slug'ами, включая `Тип двигателя`, которого нет больше нигде.
9. **`zubr.ru` вопреки ожиданиям дешёвый** — сломанный sitemap обходится корнем сайта:
   дерево из 284 категорийных ссылок лежит прямо в HTML главной.
