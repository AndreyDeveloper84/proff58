## Вердикт: 22 корректных, 18 проблемных

### ❌ Проблема 1 — `size` из диапазонов и парных размеров (15 шт.)

Правило `size` у `golovki` и `klyuchi-gaechnye` одинаковое:

```
(?<![\d.,/])(\d{1,2}(?:[.,]\d)?)\s*мм
```

Lookbehind блокирует цифру / точку / запятую / слэш перед числом, но **не блокирует `-` и
`х`**. Поэтому диапазон и пара размеров читаются как один размер — берётся второе число:

| Название | Запишет | Что на самом деле |
|---|---|---|
| Ключ для фитингов **32-75 мм** ПНД | `size=75` | диапазон 32–75, одного размера нет |
| Ключ радиусный ударный **55-65мм** | `size=65` | диапазон |
| Ключ радиусный шарнирный **50-80мм** | `size=80` | диапазон |
| Ключ универсальный **8-14, 15-22мм** | `size=22` | два диапазона |
| Ключ сантехнический **10-32мм** 250мм | `size=32` | диапазон |
| Ключ универсальный самозажимной **23-32мм** | `size=32` | диапазон |
| Ключ универсальный с крючком **9-22 мм** | `size=22` | диапазон |
| Ключ для труб **26-32мм** ЗУБР ШиреФит | `size=32` | диапазон |
| Ключ трубчатый **24х27мм** | `size=27` | двусторонний: 24 **и** 27 |
| Ключ трубчатый **36х41мм** HEYCO | `size=41` | двусторонний |
| Ключ трубчатый **6х7мм** KWB | `size=7` | двусторонний |
| Ключ трубчатый **8х9мм** (×3: KWB, Автодело, ЗУБР) | `size=9` | двусторонний |
| Ключ ступичный трещоточный **27х30мм** | `size=30` | двусторонний |

Разбивка: `klyuchi-gaechnye` — 8 из 10 сомнительных; `golovki` — 7 из 18.

**Почему это плохо не только «на бумаге»:** `size` — фильтр витрины. Раздвижной ключ
55–65 мм в фильтре «65 мм» найдётся, а в «55 мм» — нет, хотя подходит под оба. Для
двустороннего ключа 8×9 теряется половина товара.

### ❌ Проблема 2 — `motor_type` из названия типа инструмента (3 шт.)

```
[shlifmashiny] motor_type=Щёточный  matched='щеточн'
  id=45511  Щеточный шлифователь METABO S 18 LTX          (не опубликован)
  id=45512  Щеточный шлифователь METABO SE 12-115 SET     (не опубликован)
  id=45513  Щеточный шлифователь METABO SE 17-200 RT SET  ← ОПУБЛИКОВАН
```

«Щёточный шлифователь» — это **тип инструмента** (машина со щёткой-насадкой, сатинирование
и зачистка), а не тип двигателя. Keyword `щеточн` у опции «Щёточный» ловит слово из названия
класса товара. Значение недостоверно: у METABO S 18 LTX (аккумуляторная, 18 В) двигатель
вполне может быть бесщёточным — то есть правило рискует записать прямо противоположное.

**Это единственное ложное срабатывание, попадающее в опубликованный товар** (id 45513).

### ✅ Корректные (22 шт.)

- `golovki` / `klyuchi-gaechnye` — 13 одиночных размеров: «Ключ ступичный 50мм»,
  «82мм», «86мм», «30мм под трубу», «32мм», «41мм», «46мм», «50мм», «75мм THORVIK»,
  «27 мм СИБИН односторонний», «55 мм», «Т-образный 10мм», «5мм DUEL»;
- `shlifmashiny` — `power` 1000 Вт и 1900 Вт из «1000Вт» / «1900вт»; `power_source=Сеть`
  ×3 (два inferred по наличию мощности, один keyword по «220в»);
- `nozhovki` — «Ножовки по дереву 500 мм STAYER» → `length=500`, `nozhovka_for=По дереву`;
- `pilki-polotna` — «Полотно ножовочное по металлу 300мм ЗУБР» → `purpose=По металлу`;
- `vorotki` — «Набор с трещоткой WURTH» → `vorotok_type=Трещоточный` (пограничное: это
  набор, а не вороток, но значение по сути верное).

## Публикация

Опубликованных (видных покупателю) среди 40 — **11**: 8 корректных `size` у ступичных
ключей, `purpose` у полотна ЗУБР, и 2 у METABO SE 17-200 RT — из них `power_source=Сеть`
корректен, а `motor_type=Щёточный` ложный. Остальные 29 — у неопубликованных товаров.

## Что предлагаю (решение за владельцем)

1. **Не запускать глобальный `enrich_attributes` в текущем виде** — он запишет 18 спорных
   значений, из них одно ложное в опубликованный товар.
2. **Починить два правила**, затем прогнать по гейт-циклу:
   - `size`: добавить `-` и `х` в lookbehind (`(?<![\d.,/хx-])`), чтобы диапазоны и пары
     не давали одиночный размер. Побочный эффект: 15 значений просто не запишутся — это
     лучше неверных. Отдельный вопрос — нужен ли для раздвижных ключей диапазонный тип
     характеристики (`size_min`/`size_max`), но это уже расширение модели;
   - `motor_type` у `shlifmashiny`: `щеточн` слишком широкий. Варианты — сузить до
     «щеточный двигатель»/«коллекторн», либо исключить товары со «щеточный шлифователь»
     в названии. Заодно проверить, не задевает ли то же самое другие tool_type.
3. Альтернатива, если правила править сейчас не хочется, — прогнать `enrich_attributes`
   с `--path` на урезанном словаре только по тем tool_type, где план чистый
   (`nozhovki`, `pilki-polotna`, часть `shlifmashiny`).

Ни один вариант не трогает перфораторы — там план пуст, Phase 0.5 закрыта.
