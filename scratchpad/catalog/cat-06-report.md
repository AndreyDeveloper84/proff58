| 44538 | Перф. ЗУБР П-22-650 | **нет** | **0, out_of_stock** | 0 | engine-значения | **дубликат** 44520 «ЗУБР ЗП-22-650» (active, цена 5750) |
| 44540 | Перф. ЗУБР П-26-800 | **нет** | **0, out_of_stock** | 0 | engine-значения | **дубликат** 44523 «ЗУБР ЗП-26-800» (active, цена 6000) |

Причины скрытия **содержательные** по всем трём: публиковать дубликат без цены и
остатка — прямой вред (витрина покажет товар, которого нельзя купить, рядом с живым
двойником). Решение владельца принималось в предположении «готовы, держит только флаг» —
оно не подтвердилось. **Записей не выполнялось**, гейт-цикл не потребовался.

**Побочная находка для владельца:** «полный набор включая power 1100» у 44507 и
scraper-значения у 44538/44540 существуют **только в локальной БД рабочей копии**
(localhost `proff58`), на staging их нет. PARS-05 писал не в ту БД (или staging-прогон
ещё не выполнялся). Это меняет и оценку «выигрыш заморожен»: на стенде замораживать
нечего. Даже после переноса значений публикация не рекомендуется по причинам выше.

### 2.2. Правила и проба на реальных названиях

Драфт: `scratchpad/catalog/cat-06/rules_draft.json` (только number-атрибуты, select не
использован — опции создавать нельзя). Проба движком целиком на **всех 692 названиях**
(не выборка), каждое извлечение сверено глазами (`check_electrody.txt`,
`check_valiki.txt`, kisti — 23 строки в отчёте зондировки).

Найденные пробой и исправленные до записи ошибки драфта:
- хвостовой гард `(?![\d.,])` резал «150 мм,» — убран (запятая после «мм» законна;
  запятая внутри числа блокируется lookbehind);
- «ворс 12 мм», «полиакрил 10мм», «d=40мм», «D15мм», «48мм» — порог ≥ 60 для
  одиночного числа (длины валиков 60–450; ворс/диаметры меньше) + lookbehind «ворс »/«до »;
- «36x40мм» (прижимной) — reverse-pair ужесточён до диаметра ≤ 20 первым («15х70мм» → 70);
- skip_if « шт» не ловит «2шт» — оставлено сознательно: «Шубка 230мм 2шт» — две
  одинаковые шубки, значение верное, это не диапазон.

**Итоговая точность: 383 извлечения, 0 ошибок (100 %).** Диапазоны не извлечены ни
разу («электрод 2-5», «10-32»-формы блокируются lookbehind по «-»).

Покрытие (pub): electrody 141/169 (83.4 %), valiki 74/104 (71.2 %), kisti 23/106
(21.7 %). Промахи — мисклассификация типов (шпиндели/кейсы/герметики в этих типах —
вопрос к TT-контуру) и названия без размера.

**Остатки (перечислено, не умолчано):**
1. **Секции правил живут в scoped-файле** (`/tmp/cat06_rules` на стенде + scratchpad).
   В `data/attribute_rules.json` репозитория они НЕ внесены — это требует PR, а push
   только по явной просьбе. До мержа: повторный scoped-прогон возможен тем же файлом;
   глобальный прогон по задеплоенному словарю эти значения не трогает (для него они
   не managed). **Нужен PR секций в словарь** — по решению владельца.
2. Кандидаты без атрибута (шпатели→«Ширина», перчатки→«Размер», цепи→«шаг/паз» и др.) —
   §2.1, ждут решения о новых атрибутах.
3. Мисклассификация внутри типов (шпиндели/кейсы в svar-electrody, герметики/клеи в
   str-kisti, ванночки в str-valiki) — к TT-контуру, не к правилам.
4. Разделы без данных из аудита, не взятые в scope: sadovaya, zapchasti, siz, hranenie,
   hoztovary — следующие итерации по этой же методике.
