## 1. Задача 1 — критерий и preflight

### 1.1. Воспроизведение цифр

- `name ~* ^\s*яя` — **4550** ✓ (совпало с оркестратором);
- регистр: вариант `ЯЯ` встречается — 3 товара (3435 «ЯЯБур…», 10519, 15953);
  `Яя`/`яЯ` — 0; лидирующие ряды: `яя`×4531, `яяя`×9, `яяяя`×5, `яяяяя`×2;
- `яя` **не в начале** — 321 товар (напр. «Адаптер внешний RACO (соединитель-резьба
  внешняя)») — **не тронуты** (вне целевого множества по построению);
- расхождение с оркестратором по остаточным: 28 против 25 — объяснено: 3 заглавных
  `ЯЯ` (при регистронезависимом критерии они чистятся штатно, §1.3). По дублям:
  оркестратор считал товары (59+68), я считаю **пары** (63+71) — методы зафиксированы,
  список пар в §6.

### 1.2. Критерий (дословно)

1. Цель: `name ~* '^\s*яя'` (регистронезависимо).
2. Новое имя: `re.sub(r'^\s*я+\s*', '', name, flags=IGNORECASE)` — лидирующий ряд «я».
3. **Исключения-мусор (не трогаем):** остаток пуст, или без букв, или короче 2 символов.
4. Поправка после инцидента §4: если ряд съедает начало слова на «Я» («яяЯкорь»),
   снимается ровно 2 буквы — реализовано точечной корректировкой.

### 1.3. 25 остаточных — поимённый разбор

**Мусор (нет содержания) — владельцу, не трогать (5):**

| id | name | article | Остаток после снятия |
|---|---|---|---|
| 28269 | `яяя` | 10111324-262-4 | «я» — нет содержания |
| 6497 | `яяя` | РСВ-154730 | «я» — нет содержания |
| 35603 | `яяя` | 22008 | «я» — нет содержания |
| 6637 | `яяяя` | 2947-235-14 | пусто |
| 10528 | `яяя320060` | 320060 | «320060» — только цифры артикула, названия нет |

**Длинный префикс — очищены (20):** 3 верхнерегистровых (`ЯЯБур`, `ЯЯФиксирующее
кольцо`, `ЯЯХомут-стяжка`), 9 рядов по 3–5 «я» с реальным содержанием
(`Киянка 900 гр`, `Круг лепестковый`, `Смеситель`, `Шуруп. аккум`, `Лента фум`,
`Набор отверток`, `Насос дренажный`, `Умывальник`, `Головка 10мм`, `Трещотка`,
`511698,DC-Engine`), 9 имён «яяЯ-слово» (§4).

## 4. Инцидент и исправление (честно)

При ревью 20 примеров **после** записи обнаружено: правило полного ряда `^\s*я+`
перерезало 9 имён вида «яяЯ+слово»: «яяЯкорь электродвигателя…» → «корь…»,
«яяЯщик…» → «щик…» (7 якорей + 2 ящика). Первичный dry-run их не поймал, потому что
проверка «остаток содержит буквы» проходила («корь» — буквы).

Исправлено той же сессией: точечный `fix_map` (9 строк, `old → wrong → correct`),
одна транзакция, только поле `name`, fail-closed сверка текущего значения. Rollback-map
обновлена до финальных имён. Контроль: имён «корь/щик» от срезки — 0; map 1:1 — 0
расхождений из 4545.

Урок записан для трека: правила по строкам символов проверять на «съедании» живого
слова, а не только на пустоту/диапазон.
