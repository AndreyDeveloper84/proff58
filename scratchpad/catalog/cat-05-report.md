**Ответ на исходный вопрос («данных или привязок»):** в масштабе каталога не хватает
**данных**, а не привязок. Реальный дефицит привязок нашёлся ровно в одном месте —

выключенными фильтрами, либо хвостами ниже критерия, либо отсутствием самих данных.

## 1. Задача 1 — аудит (read-only, первым)

Метод: один проход по 22 156 опубликованным товарам стенда (`attrs_cache` — то, из чего
`build_facets` строит панели), свёртка по дереву (327 категорий, 205 с опубликованными),
управляемые атрибуты словаря (44), двойной гейт панели (`Attribute.is_filterable` +
`CategoryAttribute.is_filter` в цепочке). Скрипт: `scratchpad/catalog/cat-05/audit.py`,
данные: `audit_staging.json`. `tool_type` из кандидатов исключён (навигационная панель).

### 1.2. Куда делся «мёртвый груз» osnastka (625)

- `diameter` у корня (2012 значений) — **ложная тревога**: панели уже есть в дочерних
  узлах `osnastka-sverla` (1067), `osnastka-bury` (630), `osnastka-koronki` (314) —
  2011 из 2012 покрыто;
- `disc_diameter`/`bore`/`disc_type` (525/352/310) — реальный дефицит, сосредоточен в
  узле **`krugi`**: у дочерних `lepestkovye` и `shlifovalnye-zachistnye` панели есть,
  а у самого `krugi` (367 товаров непосредственно + страница узла на 607) — нет.

### 1.3. Разделы, где данных нет вообще (вход для обогащения, не «сделано»)

Заполненных управляемых значений — 0 при живом ассортименте:
`stroitelnyy` (1132 pub), `sadovaya` (894), `siz` (700), `zapchasti` (718),
`svarka` (499), `hoztovary-sad-ogorod` (400), `krepezh-i-metizy` (150),
`elektrika-i-osveschenie` (103), `legacy-zapchasti-19` (2124, легаси),
`ne-na-sayte` (72, скрытый). Пустые по публикациям: `benzo-i-pnevmoinstrument`,
`oborudovanie`, `osnastka-i-rashodniki`, `spetsodezhda-i-zaschita`,
`stroitelnoe-i-otdelochnoe`.

Причина системная: словарь `attribute_rules.json` покрывает 44 атрибута для уже
пройденных tool_type; для этих разделов правил извлечения ещё нет. Здесь заводить
привязки бессмысленно — панель самоглушится на пустых данных.

## 2. Задача 2 — доведение топа по эффекту

### 2.1. Кандидаты по критерию CAT-02 (покрытие ≥30 %, ≥3 значения, ≥10 товаров)

По всем 205 категориям критерий прошли **ровно 3 пары** — все на узле `krugi`
(pub 607, depth 2, родитель `osnastka`):

| Атрибут | Товаров | Доля | Значений | Вердикт |
|---|---:|---:|---:|---|
| `disc_diameter` | 525 | 86.5 % | 14 | **принят** |
| `bore` | 352 | 58.0 % | 5 | **принят** |
| `disc_type` | 310 | 51.1 % | 5 | **принят** |

Эффект: 607 опубликованных товаров страницы `krugi` получают 3 фильтра;
~1187 заполненных значений выходят из мёртвого груза. Top-5 не набралось — честных
кандидатов три; остальное — отклонения (§2.3), а не недобор.

### 2.2. Размещение и флаги

Привязки поставлены **на узел `krugi`**, не на корень `osnastka` (корневая протекла бы
вниз на ~20 дочерних разделов, где критерий не пройден). Дочерние узлы со своими
строками (`lepestkovye`, `shlifovalnye-zachistnye`) сохраняют closest-wins — их панели
не изменились (проверено живым запросом: `lepestkovye` отдаёт те же 3 панели).
`obdirochnye` (0 опубликованных) унаследует строки — панель самоглушится до появления
товаров. Флаги — зеркало соседних узлов: `is_filter=True`, `group=main`, `sort_order=0`;
`is_seo_facet`: `disc_type=True`, `disc_diameter`/`bore=False` (совпадает со словарём
для `krugi-shlif`).

### 2.3. Отклонённые кандидаты (с причинами)

вводящих в заблуждение имён, здесь таких нет.

## 4. За кадром (перечислено, не умолчано)

1. **Разделы без данных (§1.3)** — вход для обогащения: сначала правила извлечения
   для их tool_type, потом привязки.
2. **239 товаров с `battery_capacity` прямо на корне `elektroinstrument`** — данные
   есть, но товары не разнесены по подкатегориям; покрытие на корне 14.2 % < 30 %,
   и атрибут кураторски выключен. Вопрос классификации + кураторский, не фасетный.
3. **`avto` (`domkrat_type`, `capacity`)** — станут кандидатами после дозаписи
   значений (сейчас 22.5–22.8 % при пороге 30 %).
4. **`izmeritelnyy-instrument`** — легаси-дубль дерева измерительного (146 pub);
   требует решения владельца о слиянии/удалении, привязывать туда ничего не стал.
5. **Мисклассификация в `izmeritelnyy`** (CAT-04 §3: 36 чужеродных в `izm-ugolniki`) —
   их `wrench_type`/`disc_type`/`size` и дают хвост «мёртвого груза» раздела; лечится
   контуром Phase 8, не привязками.
