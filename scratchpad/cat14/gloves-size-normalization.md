# Таблица нормализации размеров перчаток (siz-perchatki) — на утверждение владельцу

Окно CAT-14B, задача 4. **Правила в `attribute_rules.json` для перчаток НЕ
вносятся до утверждения этой таблицы** (прямое требование владельца).
Источник форматов — `scratchpad/cat14/samples-top15.json` (20 реальных
названий) и выборки CAT-14A. `description` не используется (пуст у 100 %).

## 1. Буквенные размеры → select `size`

| Вариант в названии | Каноническое значение | slug |
|---|---|---|
| `XS`, `р-р XS` | XS | `xs` |
| `S`, `р-р S`, ` S` на конце | S | `s` |
| `M`, `р-р M` | M | `m` |
| `L`, `р.L`, `р-р L` | L | `l` |
| `XL`, `р-р XL`, `размер XL` | XL | `xl` |
| `XXL`, `р-р XXL` | XXL | `xxl` |
| `XXXL` / `3XL` | XXXL | `xxxl` |

Диапазоны — отдельные значения (как комбо-приводы в наборах), не разложение:

| Вариант | Каноническое значение | slug |
|---|---|---|
| `S-M`, `р-р S-M` | S–M | `s-m` |
| `L-XL` | L–XL | `l-xl` |

## 2. Числовые размеры → number `size_num` (или select — см. вопрос 2)

| Вариант в названии | Каноническое значение |
|---|---|
| `р-р 6` … `р-р 13` | 6 … 13 (число) |
| `р-р 11` (ANSHEL/ANSELL-линейка) | 11 |

Якорь обязателен: число берётся **только** после `р-р` / `размер` /
`р.` — голые числа в названии не размер.

## 3. НЕ размер (явно исключается)

| Фрагмент | Что это | Пример |
|---|---|---|
| `10 кл`, `10 кл.` | класс вязки | «10 кл.5-ти нитка» |
| `5-нит`, `5-ти нитка`, `10/5-нит` | число нитей | «с ПВХ 10/5-нит» |
| `(10/400)`, `(10/300)` | упаковка пар/короб | «БЕЛЫЕ (10/400)» |
| `КЩС-2`, `87-950`, `87-900` | модель/артикул | «Перчатки КЩС-2» |
| `11279-XL` | размер в **артикуле** — источником не является (только название) | арт. `11279-XL` |

## 4. Ограничение движка (блокирует буквенные размеры) — нужно решение

`attribute_extract.py` умеет: `select` — по подстроке keyword, `number` —
regex с группой → Decimal. Буквенный размер **не выразим**:

- как `select`: keyword «s»/«m»/«l» — подстрока, ловит латиницу брендов
  (`STELS`, `ANSELL`, `STAYER` содержат «s», «l»…) — ложные срабатывания;
- как `number`: «XL» не Decimal.

Варианты:
1. **Только числовые размеры** (`size_num`, number, якорь `р-р N`) — без
   правки движка; буквенные (~большинство ЗУБР/KRAFTOOL/STAYER) — в backlog
   CAT-15. Покрытие size по выборке CAT-14A упадёт с 0.60 до ~0.10–0.15.
2. **Правка движка**: regex-варианты для select (например `pattern` у
   option с якорем `\b`) — файл смежный с окном CODE-01, требует
   согласования (как и `skip_if_regex`).
3. Отложить size целиком, в CAT-14B завести только `material` и `coating`
   перчаток (keyword, выразимы без правок движка).

Рекомендация окна — вариант 3 сейчас + вариант 2 после CODE-01; вариант 1
не даёт владельцу полезного фасета.

## 5. material / coating (для справки, правила после утверждения)

- material (select): х/б (`х/б`, `хлопок`), латекс (`латекс`), нитрил
  (`нитрил`), ПВХ (`пвх`), брезент (`брезент`), кожа (`кожа`, `спилок`),
  неопрен (`неопрен`), полиэстер (`полиэстер`), п/ш (`п/ш`, `полушерст`).
- coating (select): полный облив (`полный облив`, `полным обливом`),
  частичный облив (`облив` без «полный» — проверять порядком), точка
  (`точка`), протектор (`протектор`).

75 товаров без размера (CAT-14A) — в backlog, не угадываем.
