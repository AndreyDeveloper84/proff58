# CODE-03 — Идемпотентность записи + граница слова в `skip_if`

## Что изменено в коде

### 1. Идемпотентность `enrich_attributes` (`apps/catalog/management/commands/enrich_attributes.py`)

- **Строки 298–366**: блок обработки существующего `ProductAttributeValue` теперь перед
  перезаписью сравнивает фактическое значение и источник:
  - если приоритет нового источника ниже сохранённого — `skip` (прежнее поведение);
  - если значение то же и источник не изменился — `keep`, PAV не попадает в
    `pav_update` и `attrs_cache` не переписывается;
  - если значение изменилось, либо значение то же, но источник выше приоритетом —
    `update` с явной причиной в отчёте.
- **Строка 509**: добавлен хелпер `Command._value_changed(pav, av, option)`, который
  сравнивает значения по логическому `kind`:
  - `number` — `Decimal` (равенство `10` и `10.0` работает корректно);
  - `select` — `value_option_id`;
  - `boolean` — `value_boolean`;
  - `text` — `value_text`.
- **Строки 298–299, 366**: `attrs_cache` обновляется только при `create`/`update`,
  но не при `keep`.

### 2. Граница слова в `skip_if` (`apps/catalog/attribute_extract.py`)

- **Строки 207–237**: добавлен `AttributeRules._skip_if_matches(norm, norm_kw)`.
  Правило границы зависит от формы стоп-слова:
  - без ведущего пробела (например `"комплект"`) — проверяется **граница начала**:
    матчит «комплект»/«комплекта», но не «БОЕКОМПЛЕКТ»;
  - с ведущим пробелом (например `" шт"`) — проверяется **граница конца**:
    матчит «10 шт»/«10 шт.", но не «штампованный».
- **Строка 238**: `_extract_one` вызывает `_skip_if_matches` вместо голой подстроки.

Переиспользуются уже обкатанные хелперы `_keyword_starts_at_word_boundary` и
`_keyword_ends_at_word_boundary` из `apps/catalog/tool_type.py:67, 73–77`.

## Дизайн `skip_if`

Выбрана форма: **граница начала по умолчанию + opt-in граница конца через ведущий пробел**.

Почему не строгая граница с обеих сторон:

| форма   | товаров |
|---------|---------|
| `набор ` | 816 |
| `наборе` | 2 |
| `комплект ` | 32 |
| `комплекта` | 3 |
| `комплекте` | 7 |

При обеих границах 12 товаров с словоформами вернули бы мусорные значения — регрессия
против корректных `prune`.

Почему выбрана именно эта форма:

- `"комплект"` — достаточно границы начала: «комплекта» глушится, «БОЕКОМПЛЕКТ» — нет.
- `" шт"` — нужна граница конца: «10 шт.» глушит, «штампованный» — нет.
- Словоформы "набор" (`наборе`), "комплект" (`комплекта`, `комплекте`) сохраняются,
  потому что граница начала для них выполняется.
