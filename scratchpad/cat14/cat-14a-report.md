## 4. Short-list для CAT-14B (5 кандидатов)

1. **`metchiki-plashki`** — 399 товаров, закроет ~306 (0.77). Характеристики готовы:
   блоки `metchiki`/`plashki` (`diameter`, `thread_pitch`, `thread_type`, `material`)
   переназначаются на объединённый слаг почти без правок. Главный риск — **не
   экстракция, а решение о слагах** (владелец, §1); плюс `skip_if` для держателей
   («М 6-М24» — диапазон) и наборов. Самый дешёвый и крупный выигрыш.
2. **`nabory-instrumenta`** — 157 товаров, закроет ~144 (0.92 по числу предметов).
   Фасеты: `pieces` (number), `drive_size` (select: 1/4″, 3/8″, 1/2″, комбо),
   `set_kind` (состав: инструмент/биты/экстракторы/выколотки — по ключевым словам).
   Риск низкий; единственная тонкость — разные слова «пр/предметов/шт».
3. **`krep-bolty`** — 194 товара, закроет ~97 (0.50). Фасеты: `thread_diameter`,
   `length` (оба из «М 6х 55»), `head_type` (шестигр./потай/полукруг.), `coating`
   (цинк/чёрный). Риск: вторая половина типа без размера в названии — уйдёт в backlog
   CAT-15; подтип «винт» внутри типа (потай/полукруг. — это винты) учесть в `head_type`.
4. **`siz-perchatki`** — 187 товаров, закроет ~112 (0.60). Фасеты: `size`
   (нормализованная шкала S–XXL + числовые), `material` (х/б, латекс, нитрил, ПВХ,
   брезент, кожа), `coating` (облив: полный/частичный/точка). Риск: три шкалы размеров
   — нужна таблица нормализации; 75 товаров без размера — в backlog.
5. **`zap-shchetki-ugolnye`** — 165 товаров, закроет ~60 (0.36 по габаритам) +
   код аналога у ~69 (0.42). Фасеты: `dims` (AxBxC, мм), `analog_code` (999088/CB-155…),
   `compat_brand` (HITACHI/MAKITA/BOSCH). Риск: габариты только у линейки «АНАЛОГ»;
   `skip_if` для щёток пылесоса. Покрытие скромное, но фасетный набор чёткий (3 шт.).

Суммарно short-list закрывает ~719 товаров no_attrs из 3 070 топ-15 (из 12 214 всей витрины).

## 6. Механика dry-run — факт

Подтверждено по коду (`apps/catalog/management/commands/enrich_attributes.py:65-66`):
`add_arguments` объявляет **только** `--path`; команда пишет PAV (bulk_create/update/delete),
`attrs_cache` и `ImportRun` в одной транзакции, режима «показать и не писать» нет.
Против staging не запускалась. Варианты для CAT-14C (не выбирая):

- **`--dry-run`/`--report-only` в команде** — плюс: повторяемо, тестируемо, входит в
  gate-cycle; минус: правка write-path + тесты (~день работы с тестами на rollback-семантику).
- **песочница-копия БД (`createdb -T`, как TT-17)** — плюс: ноль правок кода, полная
